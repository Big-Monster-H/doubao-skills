# 阶段 5：交付（部署 + 真机上线 + 文档 + 源码清洗 + 售后）

## 1. 部署流程

1. 环境变量注入：支付密钥/证书/商户号等只进云函数环境变量（部署脚本或控制台配置）
2. 云函数批量部署（云端安装依赖）
3. 管理后台静态托管 / HTTP 云函数部署
4. 数据库初始化（调用 init 云函数建集合 + 种子数据）
5. CMS schema 配置（云后台）
6. 支付回调地址在商户平台配置
7. 真机验证部署后各链路可用

## 2. 真机测试 + 提审发布流程（上线全流程，缺一不可）

| 步骤 | 动作 | 完成标志 |
|---|---|---|
| 1 | 开发者工具上传体验版 | 生成体验版二维码 |
| 2 | 真机联调 | 真机走通核心链路（登录→浏览→下单→支付→状态→退款） |
| 3 | **1 分钱真实支付测试** | 支付、回调、状态变更、退款全链路通过 |
| 4 | 提审材料核对 | 类目/资质/隐私/协议/后台指引齐备（见 07） |
| 5 | 提交审核 | 审核单提交成功 |
| 6 | 审核通过后发布 | 线上版本可访问 |
| 7 | 上线后回测 | 线上真机再走一遍核心链路 |

**禁止**：未做真实支付测试就宣称可上线；未核对资质就提交审核。

## 3. 三份交付文档（必须齐全，缺一份不算交付完成）

### README.md（开发者版）
- 项目结构说明、技术栈、启动/部署步骤
- 环境变量表（每个变量的含义 + 从哪获取）
- 云函数清单、集合清单
- 常见开发问题

### 《部署前准备清单》（小白版）
- 逐条可勾选：注册/AppID/商户号/证书/云环境/订阅模板/管理员 OpenID
- 每条带“去哪办 + 要什么材料 + 预计时间费用”
- 每个占位符（YOUR_APPID 等）附“从哪个后台哪条路径复制”的指引

### 《操作手册》（管理员版）
- 管理后台每个功能怎么用（审核/退款/打款/配置）
- 常见运营操作（改价、上下架、看数据）

## 4. 源码清洗（卖源码/交付前强制）

- [ ] AppID、环境 ID、订阅模板 ID、客服微信、管理员 OpenID 全部替换为 `YOUR_XX` 占位符
- [ ] 支付密钥、证书、p12/pem/key 文件排除出交付包（或明确归入 deploy.config 私密文件）
- [ ] 删除本地调试信息、测试账号、真实用户数据
- [ ] 扫描仓库确认无明文敏感信息
- [ ] deploy.config.json 不入库（提供 example 模板）

## 5. 《验收测试脚本》（交付给用户自行验证）

按核心链路编写可勾选脚本，示例：

```
☐ 打开小程序能正常登录
☐ 首页能浏览服务列表（加载→内容→空态均正常）
☐ 下单支付 1 分钱成功，订单状态变为已支付
☐ 订单列表能看到该订单
☐ 申请退款，管理员审核后金额原路退回
☐ 提现流程走通（如有）
☐ 弱网/断网时页面有兜底不白屏
```

## 6. 成本预估与账单提醒（小白最常被吓到的地方，必须写入交付文档）

- 云开发免费额度 + 超出部分的计费项（云函数调用、数据库存储、CDN 流量）
- 微信支付费率（如 0.6%）
- 微信认证费（如适用，300 元/年）
- **限额设置指引**：控制台设置用量告警/限额，防止意外扣费
- 预估月成本区间（按正常使用量）

## 7. 数据备份指引

- 云数据库定期导出（控制台/云函数）
- 建议频率：日/周导出，重要数据（订单/提现）必备份
- 备份保存位置 + 恢复方法说明

## 8. 售后 FAQ（交付即附，减少售后咨询）

常见问题清单（AI 编写，用户可直接用）：
- AppID 找不到/填错
- 支付回调没触发（检查商户平台回调地址配置）
- 证书过期/失效怎么办（商户平台重新下载，替换环境变量）
- 审核被拒常见原因
- 云开发扣费疑问
- 数据库误删如何恢复
- 订阅消息发不出去（模板字段/授权问题）
