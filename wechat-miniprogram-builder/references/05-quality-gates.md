# 质量闸门（阻塞式，任何一条不过，禁止进入下一阶段）

> 本文件所有闸门均为 **blocking**：不通过 = 未完成，禁止以任何理由跳过或降级。

## 1. 业务闸门（9 条，涉及钱/权限的核心防线）

- [ ] **G1 服务端金额校验**：所有金额相关下单/改价，服务端重新从数据库取价计算，前端价格仅作展示，禁止参与计算
- [ ] **G2 支付回调验签 + 幂等**：回调必须验签（MD5/签名验证）；重复回调不得重复改状态/重复入账；以订单当前状态判断是否已处理
- [ ] **G3 原子操作**：抢单/领取/状态变更均为条件更新（`where({_id,status})`）+ `updated===1` 校验；并发测试通过
- [ ] **G4 入口权限校验**：每个云函数入口校验身份（openid 归属 / checkAdmin）；禁止越权读他人订单、他人提现、管理接口
- [ ] **G5 集合权限最小化**：敏感集合（orders/withdrawals/users/inviteCodes/reviews）禁止客户端直读，已配置为仅云函数/管理端可访问
- [ ] **G6 密钥零前端**：商户密钥、证书、AppSecret 只存在于云函数环境变量；前端代码与仓库中无任何明文密钥
- [ ] **G7 包体积合规**：主包/分包/总包体积在微信限制内，超限已做分包拆解
- [ ] **G8 订阅消息字段匹配**：模板字段类型（thing/amount/time 等）与内容严格匹配，发送失败有日志
- [ ] **G9 内容安全**：用户 UGC（昵称/评价/投诉）经 msgSecCheck；图片经 imgSecCheck（如涉及）

## 3. 安全自测剧本（Phase 4 必须实际执行，禁止只读不跑）

AI 必须模拟攻击者逐条执行，记录“攻击方式 → 预期防御 → 实际结果”：

| # | 剧本 | 预期防御 |
|---|---|---|
| S1 | 未登录/他人身份调用订单查询 | 返回无权限/空数据 |
| S2 | 前端篡改价格字段下单 | 服务端重取价，以真实价格成交 |
| S3 | 重放支付回调 | 幂等，状态不重复变更 |
| S4 | 抢单并发（两客户端同时抢） | 仅一个成功 |
| S5 | 越权调用管理接口（非管理员） | 403 |
| S6 | 篡改订单状态（如 pending 直接改 done） | 状态机白名单拒绝 |
| S7 | 伪造邀请码/重复领取奖励 | 服务端校验 + 幂等 |
| S8 | 提交含违禁词的评价 | msgSecCheck 拦截 |
| S9 | 提现金额篡改 | 服务端按可提现余额计算 |

任何一个剧本防御失败 = 阶段 4 未完成，必须修复后重跑全部剧本。
