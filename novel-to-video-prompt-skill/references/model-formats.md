# 模型格式：H3 vs Seedance 2.5

> 来源：
> - MiniMax H3 官方仓库：<https://github.com/MiniMax-AI/MiniMax-H3>，`skills/h3-prompt-writing`
> - Seedance 2.0 社区技能（基于字节官方手册整理）：<https://github.com/dexhunter/seedance2-skill>
> - 本机 `ai-video-prompt` skill 的 H3 / Seedance 2.5 官方规范

## 共同点

- 用户自己分段贴文本。
- 台词是原文，不改写。
- 音效要写，音乐不要。
- **默认假设用户会上传参考图**（角色/场景），开头写 @语义占位；视觉部分只写动作和事件，不重复外貌/场景细节。
- 不写画风/色调；视觉一致性靠参考图。
- 时长以内容密度为准，不塞过多镜头。

## H3：先判平台

H3 是“平台决定格式，输入模式决定结构”。

| 用户在哪里跑 | 输出格式 |
|---|---|
| 海螺官网 / MiniMax API（有 Context-IR 理解改写） | 中文自然语言，只做决策补齐，**不要手工结构化** |
| 本地 ComfyUI / SGLang（无 Context-IR） | 英文结构化三字段，你就是 Context-IR |

本网页默认按**海螺官网 / MiniMax API**处理；**默认有参考图**，开头写 @语义占位。

## H3 官方硬上限

- 时长 `4–15s`，`24 FPS`，短边默认 768p；2K 需 Regenerate-2K。
- 默认有参考图，开头写 `@角色 @场景` 语义占位；用户上传素材后替换为平台实际标记。
- 台词必须是用户逐字原文，用 `<d>[语言]</d>` 包裹（本地结构化时）。

## H3 API 端模板（中文自然语言，有参考图）

```text
@角色 @场景

{一句话总概念}。

时长：{10}s，24FPS。

前2秒：{立即发生的事件，不是空镜；只写动作，不重复外貌/场景细节}。
视觉：{主体动作 + 事件推进，按时间顺序写；不描述角色长什么样、场景长什么样，参考图里已有}。
镜头：{只用官方运镜词，1–2 个镜头}。
声音：环境音{具体环境声}；动作音{具体动作声}；{无配乐 / 配乐{乐器 + 速度 + 力度变化，不写情绪词}}。
```

### 示例

输入：

> 红衣女子独立城楼之上，夜风拂动衣袂，她望向远方群山，轻声道：“该回去了。”

输出：

```text
@红衣女子 @城楼夜景

红衣女子在城楼上远眺群山，夜风吹动衣袂，她轻声说该回去了。

时长：8s，24FPS。

前2秒：红衣女子站在城楼栏杆边，夜风立即吹起她的长发与衣袂。
视觉：她独立城楼，缓缓转身望向远方群山，近景中轻声说出原文台词：“该回去了。”
镜头：先固定，后缓慢推进到近景。
声音：环境音有夜风与远处虫鸣；动作音有衣袂飘动声；无配乐。
```

## H3 本地端三字段（结构化，需要时使用）

```text
integrated_multimodal_description: [Shot 1] {风格锚定 + 场景 + 主体 + 动作 + 台词 <d>[语言]</d>} [Shot 2] At 00:SS.SSS, the camera cuts to {下一镜内容}。

overall_soundscape: {环境音 + 动作音 + 非语言人声}。

non_diegetic_music: {乐器/速度/力度变化；没有填 N/A}。
```

- T2VA 无首帧/尾帧，**不写** `<Picture N>` 对齐行。
- 首镜 `[Shot 1]` 无时间戳；后续时间戳严格递增且 ≤ 片长。
- 风格锚定写进 Shot 1 开头：`Live-action` / `2D-animated` / `3D CG` / `claymation` / `watercolor` / `vintage film`。

H3 官方运镜词表：`Zoom In / Zoom Out`、`Push In / Pull Out`、`Pan Left / Pan Right`、`Truck`、`Tilt`、`Pedestal`、`Arc Shot`、`Tracking Shot`、`Static Shot`、`Roll`、`Shake`、`POV`。可挂 `with small/large amplitude`、`at slow/fast speed`。

## Seedance 2.5 官方公式

```text
完整提示词 = [素材说明] + [一句话概括] + [具体情节描述] + [全局补充]
```

| 模块 | 写法 |
|---|---|
| 素材说明 | 每个 `@素材` 必须写清用途：角色 / 场景 / 首帧 / 尾帧 / 运镜 / 音色 |
| 一句话概括 | 主体 + 地点 + 事件 + 特殊运镜 |
| 具体情节 | 用时间戳分段写画面、动作、运镜、对白、音效和转场 |
| 全局补充 | 锁定机位、环境、灯光、声音、人物一致性与禁止项 |

本工具是纯文本输入，因此默认写**语义占位**：`@红衣女子`、`@城楼夜景`。用户上传素材后，把占位换成平台实际的 `@图片1` / `@图2` 等标记。

### 示例

输入：

> 红衣女子独立城楼之上，夜风拂动衣袂，她望向远方群山，轻声道：“该回去了。”

输出：

```text
@红衣女子 @城楼夜景

一句话概括：红衣女子在城楼远眺群山，镜头由固定转缓慢推进。

0-4s：红衣女子独立城楼，中景，夜风吹动衣袂，镜头固定。
4-8s：她缓缓转身望向远方群山，近景，月光落在脸上，轻声说：“该回去了。”，镜头缓慢推进。

全局补充：人物与城楼保持一致，月光来自人物侧上方；不额外指定画风；不出现文字和水印。

音效：夜风声，衣袂飘动声，远处虫鸣。

时长：约8s。
```

## 对话 / 内心独白

### H3 中文自然语言版

输入：

> 他推门进来，看见她坐在窗边。“你来了。”她没抬头。
> “嗯。”他走到桌前，放下一壶酒。
> “等很久了？”
> “不久。”

输出：

```text
雨夜酒馆里，男子推门而入，与窗边女子进行一段简短对话。

时长：12s，24FPS。

前2秒：男子推门而入，门扇带进一阵夜风。
视觉：中景从门外拍向屋内，窗边女子背对门口头也不抬，轻声说：“你来了。”男子走到桌前放下一壶酒，说：“嗯。等很久了？”随后两人对坐，女子抬眼看他，说：“不久。”
镜头：镜头1-2正反打，镜头3跟随男子走到桌前，镜头4固定。
声音：环境音有窗外隐约雨声；动作音有推门声和倒酒声；无配乐。
```

### H3 内心独白

输入：

> 她看着他离去的背影，指尖微微收紧。他终究还是变了。

输出：

```text
红衣女子站在门口，望着他离去的背影。

时长：5s，24FPS。

前2秒：风卷起她的裙摆，她的视线锁在远去的背影上。
视觉：中景，红衣女子站在门口，指尖微微收紧，望向长街尽头；末句内心独白“他终究还是变了。”
镜头：缓慢拉远。
声音：环境音有风声；动作音有脚步声渐远；无配乐。
```

## 差异速查

| 维度 | H3（海螺 API，有参考图） | Seedance 2.5 |
|---|---|---|
| 默认结构 | 中文自然语言决策补齐 | 官方四段式 + 时间戳 |
| 时间戳 | 不强要求 `镜头N`；写“前2秒/视觉/镜头/声音” | `0-4s`、`4-8s` |
| 参考图 | 开头写 `@角色 @场景` 语义占位，视觉只写动作 | 必须用 `@` 并写清每个素材用途 |
| 台词 | 保持原文，可用自然叙述嵌原句 | 保持原文，嵌入时间区间 |
| 音乐 | 写“无配乐”或乐器/速度/力度，不写情绪词 | 不要音乐，只写音效 |
| 典型时长 | 4–15s，24FPS | 标准 4–30s，Long Video 30–180s |
| 运镜 | 只用官方词表 | 运镜 1–2 种，不堆砌 |

## 注意事项

- H3 API 端不要手工写 `[Shot N]` 字段，避免和平台 Context-IR 冲突；本地结构化时才写。
- Seedance 上传真人脸素材会被平台拦截，但纯文本转视频不涉及此限制。
- 本 Skill 只处理用户已经分好的一段文字；一段文字太长时提示用户再分段。
