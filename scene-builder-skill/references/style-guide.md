# Style Guide

所有区域必须共用同一组全局参数。生成第一个区域前先写死。

## 固定参数

| 参数 | 固定值示例 |
|---|---|
| 俯视角度 | `45-degree oblique bird's-eye view` |
| 光照方向 | 光源东南，阴影朝西北 |
| 画种 | `anime cel shading` / `Chinese ink painting` / `realistic CG` 等，全项目只选一种 |
| 主色板 | 写死 3–5 个主色，例如暖木色 + 灰瓦 + 青绿 |
| 线稿/细节 | 远景低细节，近景中高细节，关键区域高细节 |
| 比例尺 | 人物/建筑/道具按蓝图比例，不随意放大缩小 |

## 风格预设

### 动漫赛璐璐风
- 正面：`official art, anime key visual, cel shading,`
- 负面：`realistic, 3d, photo,`

### 水墨风
- 正面：`Chinese ink painting, sumi-e, wash painting,`
- 负面：`photo, 3d, realistic, bright colors,`

### 写实 CG 风
- 正面：`Unreal Engine 5, path tracing, octane render,`
- 负面：`illustration, cartoon, anime,`

## 通用负面词

```text
text, watermark, signature, logo, pseudo text, duplicate buildings, repeated elements, inconsistent perspective, inconsistent lighting, deformed architecture
```

中文对照：文字、水印、签名、logo、伪文字、重复建筑、重复元素、透视不一致、光照不一致、建筑畸形。

## 层级细节

| 区域类型 | 细节要求 |
|---|---|
| 结构区（主殿、城门） | 高细节，单独出图 |
| 功能区（街道、院落） | 中等细节 |
| 远景（山、云、城外） | 低细节，允许大气透视虚化 |
