# Composite Guide

## 核心策略

**不让 AI 拼图。** 拼图容易出现接缝、重复元素、透视不一致。

正确做法：

1. 以蓝图作为硬约束。
2. 以第一个已确认区域作为风格参考图。
3. 让 AI 按蓝图 + 第一区域参考，重新生成一张完整大场景。
4. 关键区域的高细节图作为局部参考。
5. 远处自动施加大气透视。

## 合成提示词模板

```text
按下方蓝图重新生成一张完整鸟瞰大场景：{蓝图图/蓝图描述}。

风格参考：{第一区域图}。
局部参考：{关键区域高细节图}。

硬约束：
- 严格按蓝图布局，不新增蓝图里没有的大型建筑或水系。
- 共用俯视角度、光照方向、画种、色板。
- 远景用大气透视虚化，不画小房子窗户。
- 排除文字、水印、签名、重复元素。
```

## 局部重绘

某个区域不满意时，只重出那个区域，其他不动：

```text
只重绘{区域名}，保持其他区域不变。
{该区域的具体问题}要修正。
继续遵循蓝图、全局风格和第一区域参考。
```

## 后处理

```bash
# 远景大气透视：默认顶部是远景
python scripts/apply_atmospheric_perspective.py input.png output.png

# 有深度遮罩时更精确
python scripts/apply_atmospheric_perspective.py input.png output.png --mask depth.png

# 局部高细节图叠到底图
python scripts/stitch_zones.py --base base.png --patch detail.png --x 100 --y 120 --width 800 --height 600 --output merged.png
```

## 人工审核清单

- [ ] 大型建筑/水系是否都在蓝图里，有没有新增。
- [ ] 俯视角度、光照方向是否全图统一。
- [ ] 风格是否接近第一区域参考图。
- [ ] 是否有接缝、重复元素、伪文字、水印、签名。
- [ ] 远景是否自然虚化，没有多余细节。
- [ ] 关键区域是否达到结构区细节要求。
