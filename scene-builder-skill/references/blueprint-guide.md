# Blueprint Guide

蓝图是**规划图**，不是成品图。它只回答“区域在哪、怎么连接、谁大谁小”。

## 应该是 / 不应该是

| 蓝图应该是 | 蓝图不应该是 |
|---|---|
| 白底黑线 | 有渲染、有阴影 |
| 简单方块/矩形表示建筑 | 有详细建筑细节 |
| 虚线标道路走向 | 有透视渲染 |
| 色块分区（浅灰=建筑、浅蓝=水系） | 有云雾、有植被 |
| 只标区域名字 | 标注太多细节 |
| 指北针 + 比例尺 | 已经是一张完成的鸟瞰图 |

如果用户给的蓝图本身太细节（像成品鸟瞰图），要提醒：蓝图只定布局和位置，细节留给小场景。

## 必含元素

- 白底黑线
- 简单矩形表示建筑区
- 虚线表示道路走向
- 浅灰块表示建筑，浅蓝块表示水系
- 区域名（主殿、南门、护城河、东西市、后山等）
- 指北针
- 比例尺

## 蓝图生成提示词模板

```text
[场景名]的简洁鸟瞰规划蓝图，白底黑线，建筑设计图风格。
简单矩形表示建筑群，虚线表示道路走向，浅灰块表示建筑区，浅蓝块表示水系。
标注区域名称：[区域清单]。指北针和比例尺放在角落。
不要渲染、不要阴影、不要详细建筑细节、不要植被、不要云雾、不要透视成品图、不要文字以外的装饰。
```

## 区域清单模板

```text
区域清单：
1. 主殿（北侧山上，核心）
2. 官前广场 + 钟楼
3. 南门 + 南市
4. 北市
5. 东市
6. 后山
7. 护城河
8. 云海观景台
```

## 校验

用 `scripts/validate_blueprint.py` 检查：

```bash
python scripts/validate_blueprint.py path/to/blueprint.png
```

脚本能查尺寸、长宽比、白底比例、过饱和颜色。区域标注是否完整仍需人工确认，脚本无法 OCR。
