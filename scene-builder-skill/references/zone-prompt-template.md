# Zone Prompt Template

## 分区提示词模板

```text
[全局风格参数]
- 视角：{固定俯视角度}
- 光照：{固定光照方向}
- 画种：{全项目统一画种}
- 色板：{固定主色板}

画面内容：{本区域名称}，位于蓝图{方位/位置}。
{本区域需要画的结构骨架、功能道具、氛围装饰}

风格参考：以已确认的第一个区域为准，保持透视、光照、画种、色板一致。

负面：{通用负面词}
```

## 细节层级

### 结构区高细节版

```text
高细节特写：{主体建筑}，雕花/檐角/梁柱/门窗清晰，材质明确。
俯视角度：{固定角度}。光照：{固定方向}。
风格参考：{第一区域参考图}。
```

### 功能区中细节版

```text
中等细节：{街道/院落}，建筑轮廓清楚，不逐扇画窗户。
俯视角度：{固定角度}。光照：{固定方向}。
风格参考：{第一区域参考图}。
```

### 远景低细节版

```text
低细节远景：{山/云/城外}，允许大气透视虚化。
不要小房子窗户、不要细节纹理、不要清晰边缘。
俯视角度：{固定角度}。光照：{固定方向}。
```

## 两个小场景拼接前

先给用户选项，不要直接拼：

```text
这两个场景怎么拼？
A. 左右并排
B. A 作为前景，B 放到远处背景
C. B 作为前景，A 放到远处背景
D. 按蓝图的相对位置重新生成
```

确认后再生成。

## 外部生图模式

用户拿提示词去 MJ/SD 时：

- 输出英文提示词 + 中文对照。
- 固定全局参数和风格参考，不省略。
- MJ 不加质量词/渲染词/参数后缀；SD 自动加质量前缀和负面模板。
- 导回的图用第一个区域做风格校验，漂移明显的先重出该区域。
