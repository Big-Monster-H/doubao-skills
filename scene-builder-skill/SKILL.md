# Scene Builder Skill

## 定位

输入：一句场景描述（如“仙侠都城鸟瞰图”），或零散的小场景图。
输出：一张有透视关系、风格统一的鸟瞰大场景；既可内部生图，也可输出提示词让用户去 MJ/SD 生成后导回。

核心思路：**不让 AI 一次画整张图，而是先画蓝图定空间，再分区生成，最后合成。**

## 项目默认风格（《云深》）

默认采用**日漫赛璐璐风（ANIME_2D）**：京阿尼式细腻人物 + 新海诚式天空空气感。
- 正面默认：`official art, anime key visual, cel shading,`
- 负面默认：`realistic, 3d, photo,`
- **禁用 3D / 写实渲染词**（UE5、octane、photorealistic 等一律不写）。
- 用户明确要求其他风格时再切换 `references/style-guide.md` 里的预设。

## 脚本依赖

`scripts/` 下三个 Python 脚本都依赖 Pillow，首次使用前先装：

```bash
pip install Pillow
```

脚本是辅助工具，不是必经流程；先按 reference 走通一次流程，再决定是否调脚本。

## 启动：先判断有没有蓝图

### 情况 1：用户只有小场景图，没有蓝图

不要直接拼。告诉用户：

> 这两个图只能确定两个区域，做不出完整大场景。你有蓝图吗？
> 如果没有，蓝图就是：一张简洁的鸟瞰线稿，标注整个场景布局——城门在哪、街道从哪到哪、还有哪些区域、道路怎么连接。有了蓝图才知道小场景放在哪里、周围还要补什么。

然后：
- 用户有蓝图 → 进入情况 2。
- 用户没有 → 先按 `references/blueprint-guide.md` 出一张简洁蓝图，用户确认后再继续。

### 情况 2：用户有蓝图

确认蓝图区域清单，让用户选先补哪个区域：

```text
已完成：✅ 城门 ✅ 街道
接下来补哪个区域？
A. 主殿（北侧山上，核心）
B. 官前广场 + 钟楼
C. 南市/北市
D. 云海观景台
E. 按顺序逐个补
```

已完成的区域打 ✅，未完成的列选项。下次接着补时从上次停的地方继续，不重复生成。

### 情况 3：用户只有一句话描述

先出一张简洁蓝图，用户确认布局后再开始分区生成。

## 三层流程

| 层 | 做什么 | 关键规则 |
|---|---|---|
| 第一层：蓝图 | 定空间关系、区域清单、道路/水系走向 | 白底黑线规划图，不是成品图 |
| 第二层：分区生成 | 蓝图拆成 4–8 个区域逐个生成 | 共享同一角度/光照/画种/色板；第一个区域是风格基准 |
| 第三层：合成 | 不让 AI 拼图，按蓝图 + 第一区域参考重画完整图 | 远处大气透视；局部不满只重出局部 |

## 三层道具分离

| 层 | 内容 | 谁决定 |
|---|---|---|
| 结构骨架 | 建筑、道路、城墙、水系位置 | 蓝图阶段定死 |
| 功能道具 | 城门灯笼柱、街道路灯、主殿香炉、桥栏杆 | 蓝图阶段写死位置和种类 |
| 氛围装饰 | 树、云、雾、鸟、花瓣、远山 | AI 自由发挥 |

关键：**不要让 AI 决定“摆什么”，蓝图阶段就写清楚。**

## Working sequence

1. 判断输入状态，必要时先生成/确认蓝图（`references/blueprint-guide.md`）。
2. 从蓝图整理区域清单，让用户选择本次补哪个区域。
3. 用 `references/style-guide.md` 锁定全局风格参数：俯视角度、光照方向、画种、色板。
4. 用 `references/zone-prompt-template.md` 生成当前区域；第一个确认的区域作为后续所有图的风格参考。
5. 每补完一个区域打 ✅，继续时只补未完成区域。
6. 两个小场景要拼接前，先确认空间关系（左右并排 / 背景远近 / 其他），不直接拼。
7. 用 `references/composite-guide.md` 合成：蓝图 + 第一区域风格参考，让 AI 重画完整大场景。
8. 人工审核蓝图一致性，不满足则局部重绘或重出。

## Non-obvious invariants

- 蓝图是硬约束：合成时不得新增蓝图里没有的大型建筑/水系。
- 所有区域共用同一俯视角度、同一光照方向、同一画种和色板。
- 第一个区域是风格基准，后续所有图以它为参考图。
- 远处不要细节：用大气透视虚化，不要求 AI 在远景画小房子窗户。
- 两个小场景拼接前必须先确认空间关系，不直接开始拼。
- 提示词排除：伪文字、水印、签名、重复元素。
- 支持两种生图模式：内部生图，或输出提示词给 MJ/SD 后导回。
- 蓝图如果本身太像成品鸟瞰图，要提醒用户：蓝图只定布局，细节留给小场景。
