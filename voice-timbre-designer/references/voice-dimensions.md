# 音色维度候选词库

组装提示词时从对应维度取词，同一维度可取 1–3 个组合，避免堆砌（超过 3 个会让模型混乱）。

## 1. 性别与年龄段

| 维度 | 候选词 / 描述短语 |
|---|---|
| 性别 | 男声、女声、中性声、雌雄莫辨的伪声 |
| 童声 | 3-7岁：奶声奶气、脆生生的童音、带奶音 |
| 少年 | 8-12岁：清亮的少年音、稚气未脱 |
| 青春 | 13-17岁：少年感/少女感、变声期边缘的清亮 |
| 青年 | 18-25岁：年轻清透、元气、干净 |
| 成熟 | 26-40岁：沉稳、磁性、知性 |
| 中年 | 41-60岁：浑厚、稳重、略带岁月感 |
| 老年 | 60岁以上：沙哑沧桑、气声重、语速迟缓、慈祥或威严 |
| 无龄感 | 听不出具体年龄、悬浮的二次元感 |

## 2. 声线类型（核心组合项）

清亮、甜美、软糯、娃娃音、少女感、少年感、御姐、低沉、磁性、沙哑、烟嗓、粗犷、浑厚、温柔、中性、空灵、通透、气声、鼻腔音、胸腔音、气泡音、机械感、电子感、金属感、丝绸感、颗粒感、播音腔

**常用组合示例**：
- 元气少女 = 甜美 + 清亮 + 轻微气声
- 磁性大叔 = 低沉 + 颗粒感 + 胸腔共鸣
- 御姐 = 清亮 + 自信 + 微沙哑
- 烟嗓 = 沙哑 + 粗粝 + 慵懒
- AI音 = 电子感 + 机械 + 平直
- 空灵 = 通透 + 气声 + 飘渺

## 3. 音质细节

| 细节 | 描述短语 |
|---|---|
| 胸腔共鸣 | 声音从胸腔发出，浑厚有底气 |
| 鼻腔共鸣 | 带一点鼻音，软糯或闷 |
| 头腔共鸣 | 声音靠上，清亮穿透 |
| 气声 | 气音明显，贴着话筒说话 |
| 颤音 | 尾音带自然颤音 |
| 颗粒感 | 声音带磁性颗粒，像砂纸摩擦 |
| 丝绸感 | 顺滑柔和，毫无毛刺 |
| 金属感 | 明亮带金属光泽，有棱角 |
| 纯净度 | 干净无杂质 / 带杂质 |

## 4. 音高、语调、语速

| 维度 | 候选 |
|---|---|
| 音高 | 高亢、清亮偏高、适中、低沉偏矮、压得很低 |
| 语调 | 平直无起伏、自然上扬、波浪起伏、整体下沉 |
| 尾音 | 尾音上扬、尾音拖长、尾音干脆、尾音带颤 |
| 语速 | 极慢、慢、中速、快、极快、忽快忽慢 |
| 停顿 | 停顿多慢条斯理、极少停顿一气呵成 |

## 5. 性格气质

元气、高冷、温柔、沉稳、威严、冷酷、呆萌、傲娇、狡黠、慵懒、阳光、忧郁、神秘、飒爽、儒雅、痞气、知性、可爱、病娇、健气、沙雕、老实、精明的市侩、不怒自威

## 6. 情绪基调

平静、愉悦、悲伤、愤怒、紧张、兴奋、疲惫、嘲讽、关切、官方、热血、治愈、煽情、淡定、惊喜、不屑、讨好

## 7. 地域口音

标准普通话、东北腔、北京儿化音、天津腔、四川/重庆椒盐、陕西话、山东话、河南话、广东粤语腔、上海吴语腔、湖南塑料普通话、台湾腔、港腔、日式中文、英式中文、法语腔、韩式中文、津味

## 8. 用途场景

动漫角色配音、游戏角色、广播剧、有声书/小说演播、广告、纪录片旁白、新闻播音、短视频口播、直播带货、客服、导航/语音助手、ASMR、体育解说、歌曲念白、译制片腔、舞台剧腔、评书腔、电台深夜档

## 9. 语言

中文、英文、日文、韩文、粤语、中英混、中英日混

## 10. 风格化标签

日漫配音（元气/中二/温柔三种主腔调）、国漫配音、广播剧腔、译制片腔（字正腔圆的译制感）、电台DJ、纪录片腔（沉稳知性）、播音腔（字正腔圆、庄重）、虚拟歌姬、赛博电子、复古磁带（暖、糊、沙沙）、电话音、公放喇叭、回音室、AI助手（平直亲切）、机械合成、黑胶唱片、抖音变声

## 11. 附加细节

口头禅（如“嗯嗯”“我跟你说”“你懂的”）、笑声（爽朗大笑/轻笑/坏笑/尬笑/捂嘴笑）、呼吸感（明显换气/气若游丝）、气音、气泡音、结巴、哭腔、咬字清晰度（字正腔圆/连读吞字/咬字软糯）、口水音、娃娃音拖长

## 组装口诀

年龄性别开头 → 声线 1–3 个 → 音调语速 → 性格情绪 → 口音 → 场景风格 → 附加细节。描述用“像…一样”“带…感”“语速…，语调…”这类自然说法，写成一个通顺段落，不要列标签堆。
