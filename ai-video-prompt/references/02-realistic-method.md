# 7 段式真实感提示词法

> 来源：zhouwei713/seedance-prompt（MIT 授权）。
> 适用：真实感、去 AI 感、纪录片质感、家庭录像、DV/VHS/监控/手机随拍、怀旧生活流。

## 核心哲学

高质量真实感提示词回答一个问题：**这段素材是谁、用什么设备、在什么年代、出于什么目的拍下来的？**

一旦确定"素材来源身份"，所有细节都能推导出来：2005 年朋友随手拍的 DV 会抖、会失焦；90 年代监控没声音、俯视角、低帧率；2024 年博主手机竖屏有美颜感、会对着镜头说话。

第二个关键认知：**AI 有强烈的默认审美**（电影感运镜、完美构图、商业调色）。想要真实感，必须用负面约束关闭默认行为，并在时间轴里植入"非完美事件"。

## 四要素（第一步必先确定）

1. **拍摄者身份**：朋友/家人/路人/Vlogger/监控/纪录片摄制组/无人固定机位？
2. **设备与年代**：DV/VHS/8mm/iPhone/GoPro/监控/专业电影机？哪个年代？
3. **主体与场景**：拍谁？在哪？什么时间段？
4. **情绪目标**：温暖怀旧/孤独疏离/紧张不安/平静治愈？

信息足够就推断，输出前用一句话确认理解；不足就问 2-3 个关键问题。

## 七段式结构

```
主要角色 → 地点 → 视觉风格 → 摄像风格 → 时间轴 → 音频 → 目标
```

### 1. 主要角色
- 只写可视化具体特征：年龄段、妆容、每件衣物颜色/材质/版型、鞋、配饰、发型细节（碎发/刘海）
- 禁用抽象形容词（时尚的、好看的、有气质的）
- 加一句皮肤质感（如"逼真的皮肤纹理"）
- 加一句性格气质（驱动肢体语言）
- **一致性锁定句结尾**："在整个视频中保持一致的身份、服装、发型和外貌"

### 2. 地点
- 时间段 + 地域 + 场景类型开头
- 罗列 8-12 个具体环境元素（盆栽、晾衣绳、电线杆、树影），互相佐证同一个世界
- 加光影动态（树影移动、云影掠过）
- **负面约束结尾**：排除模型爱加的商业元素（商店、广告、人群、咖啡馆）

### 3. 视觉风格
- 4-6 个短语定义真实感层级：如"超现实主义纪录片真实感、真实的即兴行为、自然的肢体语言、无剧本的日常生活片段感、强烈的环境真实性"

### 4. 摄像风格（去 AI 感核心段）
- 把设备美学翻译成 6-10 个具体物理现象（对焦搜索、曝光波动、滚动快门、压缩伪影）
- **三连负面约束结尾**：没有稳定、没有电影化运镜、没有现代色彩分级（按设备调整）

设备缺陷参数包速查（完整版见 `references/02-realistic-method.md` 附录）：

| 设备 | 画面特征关键词 | 负面约束 |
|------|--------------|----------|
| 2000s 消费级 DV | 中等数字压缩伪影、褪色、噪点、滚动快门、高光过曝 | 没有稳定/没有电影化运镜/没有现代调色 |
| 80-90s VHS | 磁带噪点、扫描线、色彩溢出、时间码、边缘畸变 | 没有数字锐利感/没有稳定/没有 HDR |
| 8mm/Super 8 | 胶片颗粒、暖黄偏色、暗角、灰尘划痕、18fps 卡顿 | 没有同期声/没有平滑运镜/没有数字清晰度 |
| 智能手机竖屏 | 9:16、过度锐化、HDR 感、果冻效应、暗光涂抹 | 没有横屏/没有三脚架稳定/没有专业布光 |
| GoPro 运动相机 | 鱼眼畸变、高饱和、眩光、镜头水渍 | 没有第三人称跟拍/没有电影构图/没有慢动作 |
| 监控 CCTV | 固定高位俯视、低帧率、单色、时间戳、人脸模糊 | 没有摄影师存在/没有构图意识/没有声音/没有变焦跟随 |
| 专业纪录片 | 浅景深、自然光、克制调色 | 没有摆拍感/没有采访灯光/没有戏剧化运镜 |
| 网络摄像头 | 低清晰度、块状伪影、顶光青白、固定机位 | 没有电影机位/没有稳定/没有专业收音 |

### 5. 时间轴
- 总长 10-15s，切 5-7 镜，每镜 2-3s，用 `00:00–00:02` 格式
- 每镜三层：**主体动作 + 环境呼应（风/光/动物/路人）+ 一个非完美事件**
- 非完美事件 7 镜内不重复
- 动作间要有生活逻辑链（坐着 → 走进小巷 → 遇到猫 → 晾衣服）
- **结尾必须有收束**：突然切黑（像关机）、走出画面、镜头垂下拍到地面，与拍摄者身份匹配

### 6. 音频
- 先声明模式（仅自然环境音 / 现场收音+环境）
- 罗列 6-9 个具体声音元素，与场景元素一一对应（有猫就有猫叫，有晾衣绳就有织物声）
- **三连否定结尾**：没有音乐、没有音效设计、没有旁白（按需调整）

### 7. 目标
- 一句话灵魂锚点："捕捉 XX，仿佛一段 XX 的 XX，用 4-6 个形容词收尾"
- 是模型在细节冲突时的取舍依据，必须与全篇自洽

## 非完美事件库（时间轴取材）

1. 一阵风把头发吹到脸上，她别到耳后
2. 脚下被石子绊了一下，稳住后继续走
3. 对焦在脸和手中物体之间来回切换
4. 手指擦过镜头边缘，画面出现短暂模糊
5. 曝光在明暗交界处波动了一下
6. 突然想起什么，脚步停住又继续
7. 整理头发、拨发到耳后等无意识小动作
8. 动作做到一半改变主意（伸手拿杯子又先擦了下桌子）
9. 说话被环境音打断，笑场

## 收束方式（结尾必选一个）

1. 录制中途突然切黑，仿佛摄像机关闭了
2. 主体走出画面，镜头停留在空景两秒
3. 镜头垂下拍到地面/脚，然后切断
4. 有人喊拍摄者名字，镜头晃向声源时切断

## 常见翻车模式

1. **段落信息串味**：把运镜写进角色段、把音乐写进视觉段，严格分区
2. **非完美事件堆太多**：一个镜头塞三个失误反而假，一镜一个
3. **负面约束与正面描述打架**：前面写"没有电影化运镜"，时间轴又写"缓慢推轨"
4. **音画不对应**：画面没有猫，音频写了猫叫
5. **时代穿帮**：2000 年代 DV 里出现智能手机、共享单车、现代广告屏
6. **收束缺失**：视频停在一个"正在进行"的动作上，像被截断而非完整记录

## 自检清单

- [ ] 角色段：全部可视化特征？零抽象形容词？有一致性锁定句？
- [ ] 地点段：8 个以上具体元素？有光影动态？排除了商业元素？
- [ ] 视觉风格段：4-6 个真实感定义短语？
- [ ] 摄像段：至少 6 个物理缺陷？结尾至少 3 个"没有 XX"？
- [ ] 时间轴：5-7 镜？每镜三层结构？非完美事件不重复？有生活逻辑链？有收束？
- [ ] 音频段：声音与画面一一对应？三连否定？
- [ ] 目标段：一句话锚点与全篇自洽？
- [ ] 全文无"美丽/电影感/高级/唯美"等抽象词？
