# 画风对标作品联网调研指南

> 核心原则：**对标作品由用户提出**，不要替用户预设画风。用户提出后，联网搜索该作品的具体视觉特征，再写成可执行描述。

## 为什么用作品名，不用工作室名

模型对"京阿尼 / Kyoto Animation / 新海诚"这类工作室名理解不稳定，常输出错误画风。但对具体作品名（《紫罗兰永恒花园》《你的名字》）命中率高得多——训练数据里作品名与视觉特征强绑定。

## 联网调研流程

用户提出对标作品（如"想要《紫罗兰永恒花园》那种感觉"）后：

1. 搜索「[作品名] 美术风格 / 视觉特征 / art style」
2. 搜索「[作品名] 角色设计 / 色彩设计 / 摄影运镜 / 背景美术」
3. 参考来源：维基百科、萌娘百科、动画/电影分析文章、官方设定集、B站/知乎/豆瓣解析、Pinterest 视觉板

## 六维拆解框架

把调研结果拆成六维可执行描述，缺哪维补哪维：

| 维度 | 要回答的问题 | 提炼方向示例 |
|------|-------------|-------------|
| 人物画风 | 线条粗细？发丝？五官比例？眼睛画法？ | 柔和线条、发丝根根分明、眼型圆润 |
| 背景渲染 | 手绘/照片级/水彩/CG？ | 水彩质感、超写实照片级、手绘赛璐璐 |
| 光影 | 逆光/柔光/体积光/色调？ | 柔和暖光包裹轮廓、丁达尔光、蓝紫天空 |
| 色彩 | 主色调/饱和度/对比？ | 低饱和、暖金+翡翠绿、高饱和原色 |
| 特效 | 粒子/光斑/拖尾？ | 刀光拖尾、粒子特效、镜头光斑 |
| 运镜 | 固定/缓推/环绕/动态3D？ | 缓慢运镜、一镜到底、动态运镜 |

## 写成提示词的格式

调研后写成「《作品名》+ 具体技法」，不写「工作室名」：

```
❌ 旧：Kyoto Animation style / 京阿尼风格
✅ 新：《紫罗兰永恒花园》动漫风格，柔和暖光包裹人物轮廓，
       发丝根根分明，背景如水彩渲染
```

## 角色 / 背景 / 特效拆开写

动漫类不要写整体模糊词，按来源拆开对标：

```
人物 = 《作品A》角色画风（柔和线条、细腻发丝）
背景 = 《作品B》渲染风格（超写实、逆光、立体云层）
特效 = 《作品C》粒子（刀光拖尾、体积光）
```

## 格式示例（仅供参考，非预设答案）

以下示例仅演示「调研结果如何组织成提示词」，实际使用时**以用户提出的作品为准，联网调研后填写**：

- 柔和少女情感 → 调研《紫罗兰永恒花园》后提取：柔和暖光、细腻发丝、水彩背景
- 超写实背景 → 调研《你的名字》后提取：逆光大光斑、蓝紫天空、立体云层、丁达尔光
- 史诗战斗 → 调研《鬼灭之刃》后提取：3D运镜、粒子特效、体积光、刀光拖尾

## 无明确对标时

用户没提对标作品，先问一句。用户确实无所谓时，才按「最接近的作品名 + 风格偏移描述」或「3 个作品名三角定位」推进，不要单方面定死画风。
