# 人工审核清单

> 每个阶段都要人工审核，审核通过才进入下一阶段。这是用户明确要求的生产规范。

## 审核节点总览

```
需求解析 → [审核1] → 提示词生成 → [审核2] → 分镜 → [审核3] → 交付
```

| 节点 | 审核什么 | 不过关怎么办 |
|------|---------|-------------|
| 审核 1 | 方向对不对 | 改方向，重新解析 |
| 审核 2 | 提示词是否达标 | 只重写对应段落 |
| 审核 3 | 分镜是否连贯 | 重写分镜，不动提示词结构 |

## 审核 1 · 需求解析

在生成提示词前，先让用户确认理解正确。通过标准：

- [ ] 视频类型判断正确？（产品/动漫/叙事/艺术/教育/社交）
- [ ] 时长与镜数符合预期？
- [ ] 素材情况明确？（纯文字/图生视频/首尾帧/多模态）
- [ ] 画风对标作品是用户提出的，不是替用户定的？
- [ ] 目标模型确认？（默认即梦 Seedance）

**输出一句话确认**："我理解为：{类型}，{时长/镜数}，{素材}，画风对标《{作品}》，目标模型 {模型}。对吗？"

## 审核 2 · 提示词生成

提示词写完后，先让用户看，不要直接交付。通过标准（对照 `references/04-lint-rules.md`）：

- [ ] 九维度基本齐全（人物/环境/光影/构图/色彩/风格/材质/运镜/声音）
- [ ] 8 条铁律全过（禁空泛词/摄影机型号/呼吸句/声音行/瑕疵/留白/避IP/长度）
- [ ] 负面提示词正确（名词短语、与正面自洽）
- [ ] 画风是对标作品的真实特征（联网调研过，不是瞎写）
- [ ] 图生视频的 @素材 标注清楚

**输出说明**：2-3 句写作意图 + 指出最值得调的部分。

## 审核 3 · 分镜

多镜作品才需要此节点。通过标准：

- [ ] 每镜有景别+角度+运镜+时长+画面内容
- [ ] 角色/氛围一致性锁定（多镜不漂移）
- [ ] 情绪曲线完整（起承转合）
- [ ] 每镜信息密度适中（单镜 ≤15s）
- [ ] 结尾有收束/留白
- [ ] 动漫类每 4-5 镜有"間"空镜

## 交付前最终检查

对照 `references/04-lint-rules.md` 的交付清单 + `references/10-negative-prompt.md` 的自检，全过才交付。

## 审核记录建议

每次审核留一句话记录，方便迭代：

```
[审核1] 方向：动漫，15s单镜，对标《紫罗兰》，即梦 → 通过
[审核2] 九维度齐全，铁律全过 → 通过
[审核3] 单镜无需分镜审核 → 跳过
```

## 用户反馈修改规则

- 用户反馈改某段 → **只重写对应段落**，不重发全文
- 用户说"感觉不对"但说不出哪里 → 回到审核 1，重新确认方向和画风
- 连续 2 次不过 → 换方法论（如电影感换真实感）
