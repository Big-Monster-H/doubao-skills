# 文生图提示词规范（Stage A · 关键帧/首帧）

> 生产流程是**文生图 → 图生视频**。这一步产出的是静态图提示词：关键帧、首帧、角色设定图、场景图。
> 视频提示词（Stage B）见 `references/01~03`，两者不要混：静态图**没有时间轴、没有运镜、没有声音**。

## 文生图 vs 视频提示词

| 维度 | 文生图（Stage A） | 图生视频（Stage B） |
|------|------------------|---------------------|
| 时间轴 | ❌ 无 | ✅ 按秒/按镜切片 |
| 运镜 | ❌ 只写固定机位/视角 | ✅ 运动类型+幅度+速度 |
| 声音 | ❌ 无 | ✅ 环境音/对白/配乐 |
| 构图 | ✅ 重点（三分法/景别/角度/景深） | 次要（延续首帧构图） |
| 细节 | ✅ 重点（发丝/材质/纹理/瑕疵） | 延续图，描述动作变化 |
| 画风 | ✅ 重点（作品名锚定） | 延续图，写动作 |

## 文生图九维度（去掉运镜/声音，强化构图/细节）

| 维度 | 要写清楚 |
|------|---------|
| 主体 | 年龄/体型/面容/发型/服饰/配饰/姿态/表情 |
| 环境 | 地点/建筑/地面/植被/空间层次（前景/中景/远景） |
| 光影 | 主光源方向/色温/强度/阴影/氛围光 |
| 构图 | 主体在画面位置/景别/角度/景深/视线引导 |
| 色彩 | 主色调/饱和度/对比/色彩重心 |
| 画风 | 对标作品名 + 具体技法（不是工作室名） |
| 材质 | 每样东西的材质/反光率/纹理 |
| 细节 | 瑕疵/纹理/发丝/褶皱/磨损（真实感来源） |
| 情绪 | 画面传达的情绪 + 表情/姿态配合 |

## 三种图的不同用途

| 图类型 | 用途 | 提示词重点 |
|--------|------|-----------|
| 角色设定图 | 锁定角色一致性（多镜作品） | 角色九维度写满，全身/半身，正面/背面 |
| 场景图 | 锁定环境（多镜作品） | 环境/光影/色彩写满，无人物或人物次要 |
| 首帧图 | 图生视频的真实起点 | 构图+主体状态，是视频 0 秒画面 |

## 构图规范

- **主体位置**：居中 / 左三分线 / 右三分线 / 下三分之一，明确写
- **景别**：特写/近景/中景/全景/大全景
- **角度**：平视/仰拍/俯拍/过肩/高空俯拍
- **景深**：浅景深（主体清晰背景虚化）/ 深景深（全清）
- **视线引导**：观众先看哪→再看哪→停留哪

## 画风锚定（文生图最看重）

用对标作品名 + 具体技法（用户提出作品 → 联网调研，见 `references/06-art-style-library.md`）：

```
❌ 京阿尼风格
✅ 《紫罗兰永恒花园》动漫风格，柔和暖光包裹人物轮廓，
   发丝根根分明，背景如水彩渲染
```

## 负面提示词（图像特有）

`多余手指、畸形手指、手部粘连、肢体变形、五官不对称、面部崩坏、塑料皮肤、过度磨皮、低分辨率、水印、文字乱码、马赛克`

## 文生图提示词模板

```
主体：{年龄}{身份}，{体型}，{面容}，{发型颜色+长度}，
      {服装颜色/材质/版型}，{配饰}，{姿态}，{表情}。
环境：{具体地点}，{建筑}，{地面}，{植被}，
      前景{…}，中景{…}，远景{…}。
光影：{主光源方向}，{色温}，{强度}，{阴影}，{氛围光}。
构图：{主体位置}，{景别}，{角度}，{景深}，{视线引导}。
色彩：{主色调}，{饱和度}，{对比}。
画风：《{对标作品}》{具体技法}，{材质}，{细节}。
情绪：{氛围}。
负面：{多余手指、畸形、崩坏、水印…}
```

## 自检清单

- [ ] 九维度齐全（主体/环境/光影/构图/色彩/画风/材质/细节/情绪）
- [ ] 构图明确（主体位置/景别/角度/景深）
- [ ] 画风用对标作品名（不是工作室名）
- [ ] 材质和瑕疵细节写了（真实感来源）
- [ ] 没有时间轴/运镜/声音（这是视频提示词的内容）
- [ ] 负面提示词写了图像特有伪影
