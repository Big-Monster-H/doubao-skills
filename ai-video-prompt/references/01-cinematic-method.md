# 5 段式电影感提示词法

> 来源：Mx-Shell《丧尸清道夫》方法论（MIT 授权，经 jnMetaCode/ai-shortfilm-prompts 结构化）。
> 适用：电影感、特效变身、史诗大场面、战斗、去 CG 感、商业大片质感。

## 一句话总结

**像写分镜脚本一样写提示词，而不是像写文学描述。** 把场景按时间切片，每一秒分别交代「动作 / 镜头 / 特效 / 声音」。

## 5 段式结构（顺序不要乱）

```
1. 核心主题       ← 给 AI 定调子（一行 tag）
2. 人物与基础设定 ← Who & What is wearing
3. 氛围与画质     ← How it looks
4. 运镜规则       ← How the camera moves
5. 分镜（时间轴） ← 按秒/按镜头展开剧情
```

### 段 1 · 核心主题

一行风格标签，用 `|` 或 `丨` 分隔，3-6 个标签，从"画面类型"到"题材"到"美学风格"层层递进。

```
核心主题：写实暗黑特摄 | BLACK SUN美学 | 破碎肉身 | 战损变身 | 末日战场
核心主题：原子朋克 | 末日丧尸 | 电影级质感 | 超写实 | 杜绝游戏 CG 感
```

关键词池：
- 真实感锚点：电影级质感、超写实、真人实景拍摄、杜绝游戏 CG 感、变形宽荧幕电影质感
- 美学定调：暗黑写实、原子朋克、蒸汽朋克、赛博朋克、废土工业、复古港风
- 题材：特摄剧、末日生存、孤胆英雄、机械武侠、重型机甲
- 情绪：破碎肉身、战损变身、肃杀、磅礴史诗、压抑沉重

### 段 2 · 人物与基础设定

回答"画面里有谁、穿什么、站在哪"，三行：**面部 / 服装 / 场景**。

```
【人物与基础设定】
面部：五官、脸型、发型还原，杜绝美化。保留轻微面部瑕疵。
      表情全程阴郁。眉心轻微蹙起，拒绝昂扬斗志与眼神高光。
服装：哑光黑色皮质长风衣，金属腰带为哑光质地，腰带核心为暗红色水晶。
场景：末日战场，微风，硝烟弥漫，阴天荒野，灰蓝色调天空。
      天空中划过带有火焰与浓烟的陨石。
```

三个反直觉要点：
- **"杜绝美化"**：真实感来自瑕疵，"保留轻微面部瑕疵"比模糊说"高质量"管用得多
- **服装写质地**："哑光黑色皮质"比"黑色皮衣"信息量大三倍
- **场景写动态环境**：微风、硝烟、陨石，静态背景出不了氛围

### 段 3 · 氛围与画质

模拟"真实摄影机 + 镜头"，给 AI 一个明确的视觉风格锚点。

```
【氛围与画质】
视觉基调：变形宽荧幕电影质感。模拟 IMAX 胶片摄影机，
        搭配 Panavision C 系列镜头（焦段 35mm，光圈 f4）。
色彩与影调：低饱和灰蓝主调。暗部信息压缩，保留细节。
          边缘添加轻微柔焦与适度的胶片颗粒感。
风格核心：参考《XXX》美学风格。营造压抑、沉重的实拍肉身痛苦感。
```

摄影机 + 镜头查表：

| 风格 | 摄影机 + 镜头 |
|------|--------------|
| 史诗/大场面 | IMAX 胶片机 + Panavision C 系列（35mm, f/4） |
| 暗调赛博/硬科幻 | Sony Venice + Canon K-35 系列 |
| 港片/武侠 | Kodak 35mm 复古胶片，漂白旁路 |
| 商业人像 | Canon EF 85mm f/1.2 |

色调常用词：低饱和灰蓝 / 好莱坞青橙 / 60 年代复古暖橙+海盐蓝 / 暗调低光高对比。

### 段 4 · 运镜规则

三行：**单镜头 / 角度 / 呼吸感**。

```
【运镜规则】
单镜头：一镜到底，无剪辑。
角度：开场仰拍，人物半身左侧面 30 度。极缓环绕至正面平视。
呼吸感：手持拍摄，全程保持极其轻微的、如呼吸般的镜头浮动，增强临场感。
```

景别/角度/运动词池：
- 景别：极近特写/特写/近景/中景/全景/大全景
- 角度：仰拍/俯拍/平视/过肩/高空垂直俯拍
- 运动：极缓前推/环绕/跟随/固定机位/FPV/后拉+下降+上摇
- 节奏：极缓/匀速/突然/应激性 0.1 秒微颤/极慢动作

### 段 5 · 分镜（时间轴）

**写法 A · 按秒切片**（单镜一镜到底：变身、武器充能）：

```
0-3秒 · 凝视
动作：主角略微低头，目光锁定腰带，右手缓慢抬起握住主体。
镜头：极缓向前推进，捕捉身体因呼吸产生的微幅起伏。
特效：整颗眼球骤然亮起白金色光芒，眼眶周围皲裂。

3-6秒 · 启动
声音：低语「HENSHIN」。
动作：手掌用力按压腰带核心，核心开裂，红光随裂纹亮起。
镜头：低频嗡鸣由远及近，镜头随之产生应激性 0.1 秒微颤。
特效：金属机械装置被暴力唤醒，空气向内塌陷。
```

每片三件套：**动作 + 镜头 + 特效**，可选加声音/面部。

**写法 B · 按镜头切片**（多镜剪辑：叙事、MV、丧尸清道夫）：

```
分镜一：
景别：中景，机器人腿部以上。
构图：机器人背影居中，背景左侧落地窗，右侧吧台。
运镜手法：跟随运动拍摄。
画面内容：机器人背对镜头移动，手舞足蹈进入别墅，潇洒转身。

分镜二：
景别：全景，平视吧台全貌。
构图：下方三分之一为吧台，上方为酒柜。
运镜手法：镜头缓慢前推，渲染氛围。
画面内容：吧台后传来悉悉簌簌的声音，像有什么东西在翻找。
```

每镜四件套：**景别 + 构图 + 运镜手法 + 画面内容**。

## 7 条规则

1. **禁空泛夸词**：完美/震撼/史诗/帅气/4K/质感满满，模型对这些词响应差
2. **写摄影机+镜头型号**：给视觉锚点
3. **呼吸句原样照抄**：`手持镜头。全程保持一种极其微弱、类似呼吸般的镜头浮动，以增强临场感。`（两个限定词缺一不可，否则变剧烈抖动）
4. **声音行必写**：`声音：无配乐，仅保留现场同期声。`（否则模型自己编配乐）
5. **≥2 处瑕疵**：战损/掉漆/关节油污/面部细小瑕疵/战甲远非平整，完美=假
6. **结尾不堆特效**：不写刺眼强光/爆炸/胜利姿势/跃向天空/镜头炸白
7. **避免 IP 名**：Seedance 对 IP 过滤严。用"原子朋克红金战甲"替代"钢铁侠"；用户坚持写 IP 时，末尾加警告行

## 留白结尾模板

```
无对白。无爆炸。无强光。只有{{主体}}{{动作}}，{{环境细节}}。
```

示例：*"只有一个穿着未完成战甲的身影站在原地。风卷起战场硝烟。一颗流星划过远空。"*
