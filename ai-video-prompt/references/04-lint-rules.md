# 提示词规范与质量自检

> 每次交付提示词前必读。规则跨方法论通用。

## 十二条铁律

1. **禁空泛夸词**：完美 / 震撼 / 史诗（单独）/ 高级 / 帅气 / 4K / masterpiece / cinematic（单独）/ 质感满满 / 高清
   - 这些词模型训练数据里太多，单独出现无法锚定具体视觉
   - 要表达质感就写具体：摄影机型号、材质、光影、瑕疵
2. **写摄影机 + 镜头型号**：IMAX 胶片机 + Panavision C（35mm, f/4）等，给视觉锚点
3. **呼吸句原样照抄**：`手持镜头。全程保持一种极其微弱、类似呼吸般的镜头浮动，以增强临场感。`
4. **声音行必写**：`声音：无配乐，仅保留现场同期声。`（有标志性环境音要逐项列出）
5. **≥2 处瑕疵**：战损/掉漆/关节油污/面部细小瑕疵/边缘磨损，完美=假
6. **结尾留白**：不写刺眼强光/爆炸/胜利姿势/跃向天空/镜头炸白
7. **避免 IP 名**：用"原子朋克红金战甲"替代"钢铁侠"；用户坚持写 IP 时末尾加警告行
8. **长度与镜数**：单镜 ≤15s（Seedance 2.5 标准 ≤30s），多镜 ≤8 镜
9. **单一动作弧**：一个镜头只写一个连续的、有起点和终点的动作。❌`站起、走路、坐下、拿手机`（四个不相关动作塞进 30s 会仓促过渡）✅`她站在窗边，缓慢转身面向镜头，双臂交叉`
10. **运镜上限 1-2 种**：一个短镜头只用 1-2 种有效运镜。同时塞推+摇+环绕+升降会产生浑浊不稳定的运动。一个决定性运镜比四种更好。
11. **结束状态必写**：每条提示词必须有明确的结束姿态/位置/构图。有动作但没结束状态 = 结尾突然中断。
12. **正向描述优于否定**：不要依赖 negative prompt 或"不要 X"。否定不一定是硬控制，更稳妥的做法是描述期望的正向状态，并删除冲突要求。✅`稳定手持，自然肤色` ❌`不要抖动，不要肤色异常`

## 禁词清单（Lint 命中）

| 类别 | 禁词 | 替代写法 |
|------|------|----------|
| 空泛夸词 | 完美、震撼、史诗、高级、帅气、唯美、绝美 | 写具体物理现象 |
| 技术参数堆砌 | 4K、HDR、60fps、8K | 摄影机型号 + 焦段 + 光圈 |
| 泛风格词 | masterpiece、cinematic（单独）、best quality | 对标作品名 + 具体技法 |
| 混用风格 | 京阿尼+新海诚+飞碟社同时堆 | 选一个主导，其余做三角定位 |
| IP 名 | 钢铁侠、高达、假面骑士、Kamen Rider | 原子朋克红金战甲 / 描述性替代 |

## 九维度检查框架（单镜提示词）

每个镜头尽量覆盖，缺一不可。这是"准确度"的核心：

| 维度 | 要回答的问题 |
|------|-------------|
| 人物 | 不看文字能画出这个人吗？（年龄/体型/面容/发型/服饰/配饰/姿态/表情/动作） |
| 环境 | 能定位到具体地点吗？（建筑/地面/植被/空间层次：前景1m/中景5m/远景20m） |
| 光影 | 光从哪来/什么色温/多强？（主光/辅助光/光柱/焦散/阴影/粒子照明） |
| 构图 | 人物在画面哪个坐标？视线怎么走？景深如何？ |
| 色彩 | 几个主色？占比多少？饱和度/对比度？ |
| 风格 | 引用了具体作品的具体什么技法？（不是"京阿尼风"） |
| 材质 | 每样东西什么材质/反光率/透明度？ |
| 运镜 | 镜头怎么动？（景别/角度/运动/节奏/呼吸感） |
| 声音 | 现场同期声？环境音逐项？对白？配乐？ |

> ⚠️ 注意：九维度是"密度"标准，不是"字数"标准。密度≠长，400 字也可能缺维度（如之前的京阿尼方案缺人物、环境、光影、声音），200 字也可能维度齐全。**按维度检查，不按字数检查。**

## 动作节拍原则

动作要用节拍/计数描述，让模型能锚定时间点：

| 弱描述 | 强描述 |
|--------|--------|
| `演员走过房间` | `演员走四步到窗边，停顿，最后一秒拉上窗帘` |
| `角色快速移动` | `骑车人蹬三下，刹车，停在斑马线前` |
| `她走向镜头` | `她向前走三步，停在镜头前，微微抬头` |
| `物体掉落` | `玻璃杯从桌边滑落，镜头跟随下坠，撞击地面碎裂` |

核心：动词+名词指向可见结果，节拍/计数锚定时间。

## 冲突检查

交付前通读全文，检查是否存在互相冲突的要求：

- 前面写"固定镜头"，时间轴又写"缓慢推轨" → 冲突
- 前面写"无配乐"，后面又写"恢宏大气的背景音乐" → 冲突
- 画面没猫，音频写了猫叫 → 音画不对应
- 三个工作室风格同时堆（京阿尼+新海诚+飞碟社）→ 风格混用
- 首帧图里是白天，提示词写"夜晚霓虹" → 与输入素材冲突

发现冲突时，保留一个方向，删除另一个。

## 详细 vs 轻提示词

| 维度 | 详细提示词 | 轻提示词 |
|------|-----------|---------|
| 效果 | 控制与一致性 | 创意自由与惊喜 |
| 适用 | 产品广告、角色一致性、精确分镜 | 氛围探索、概念发散、艺术实验 |
| 写法 | 九维度齐全 + 时间戳 + 摄影机参数 | 风格+主体+一个动作，其余开放 |
| 风险 | 模型可能不完全遵循所有细节 | 结果不可控，可能偏离预期 |

> 同一提示词多次生成会得到不同结果——这是特性不是 bug。第 2、3 次抽卡可能比第 1 次更好。

## 单变量迭代法

看到结果后，**一次只改一个变量**：

| 现象 | 只改这一项 |
|------|-----------|
| 画面几乎不动 | 增加一个有起点和终点的可见动作 |
| 主体身份变化 | 删除新增外貌细节，只写必须保持的部分 |
| 运镜随机 | 保留一种与画面揭示相关的运镜 |
| 结尾突然中断 | 增加明确结束姿态/位置/构图 |
| 首尾帧跳变 | 写清两帧之间逐步发生的变化 |
| 参考素材混合 | 点名每个编号素材及其用途 |
| 对白被改写 | 把原句单独放入简短说话指令 |
| 否定没效果 | 改写成期望的正向状态，删除冲突 |

> 不要同时改动作+运镜+灯光，否则不知道哪个变量起了作用。

## 常见翻车模式

1. **字数多但密度低**：400 字全是形容词，没有可拍摄的具体信息
2. **段落信息串味**：运镜写进角色段、音乐写进视觉段
3. **负面约束打架**：前面写"没有电影化运镜"，时间轴又写"缓慢推轨"
4. **音画不对应**：画面没猫，音频写了猫叫
5. **风格混用**：三个工作室风格堆一起，模型各取一点导致四不像
6. **结尾堆特效**：爆炸/强光/胜利姿势堆满，反而显假
7. **时代穿帮**：2000 年代 DV 里出现智能手机、共享单车
