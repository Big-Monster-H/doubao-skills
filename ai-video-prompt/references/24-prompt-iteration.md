# 提示词迭代与强弱对比指南

> 写提示词不是一次成型，而是迭代过程。本文件提供迭代方法论、强弱提示词对比、A/B 测试框架和提示词日志格式。

## 核心原则：提示词是方向，不是结果保证

- 同一提示词多次生成会得到不同结果——这是特性不是 bug
- 详细提示词 = 控制与一致性；轻提示词 = 创意自由与惊喜
- 看到结果后，**一次只改一个变量**
- 完美提示词通过系统化精炼产生，不是灵感爆发

## 迭代策略（四步法）

```
第 1 步：从简单开始
  仅核心主体 + 一个动作 + 风格
  ↓ 生成 2-3 次，观察基线
第 2 步：添加一个元素
  测试单个添加（运镜/光影/环境/声音）
  ↓ 对比前后差异
第 3 步：记录有效内容
  保留有效短语，删除无效或负面的
  ↓ 建立个人提示词库
第 4 步：A/B 测试措辞
  相同概念，不同词语（"缓慢推近" vs "dolly in"）
  ↓ 固定最有效的措辞
```

## 弱提示词 vs 强提示词

### 环境描述

| 弱 | 强 |
|----|----|
| `一条美丽的街道` | `潮湿的沥青路面，斑马线，霓虹灯在水坑中反射` |
| `一个漂亮的房间` | `柔和的窗光 + 暖色台灯补光，走廊冷色边缘光，主色：琥珀色/奶油色/胡桃棕` |
| `夜晚的城市` | `雨夜街道，霓虹招牌在积水中反射，远处车灯拖尾` |

### 动作描述

| 弱 | 强 |
|----|----|
| `角色快速移动` | `骑车人蹬三下，刹车，停在斑马线前` |
| `演员走过房间` | `演员走四步到窗边，停顿，最后一秒拉上窗帘` |
| `她走向镜头` | `她向前走三步，停在镜头前，微微抬头` |
| `物体掉落` | `玻璃杯从桌边滑落，镜头跟随下坠，撞击地面碎裂` |

### 风格描述

| 弱 | 强 |
|----|----|
| `电影感` | `变形宽银幕 2.0x 镜头，浅景深，体积光` |
| `高质量` | `35mm 胶片，柯达 Portra 400 色调，细颗粒` |
| `动漫风格` | `京都动画《紫罗兰永恒花园》风格：柔和水彩背景，精致线条，暖色调，柔光` |
| `真实感` | `手持纪录片风格，自然肤色，轻微镜头呼吸，现场同期声` |

### 镜头描述

| 弱 | 强 |
|----|----|
| `电影镜头` | `广角建立镜头，平视；浅景深（主体清晰，背景虚化）` |
| `镜头移动` | `缓慢倾斜镜头；手持 ENG 摄像机` |
| `特写` | `中近景，从背后微角度；35mm 虚拟镜头` |

### 灯光描述

| 弱 | 强 |
|----|----|
| `明亮的房间` | `柔和窗光 + 暖色台灯补光，走廊冷色边缘光` |
| `好看的光` | `低角度晨光（07:30），银色反光板补光，对面负填充` |
| `氛围感` | `暖背光 + 柔和轮廓光；主色锚定：琥珀/奶油/胡桃棕` |

## 单变量修复表

看到结果后，根据现象只改一个变量：

| 现象 | 常见原因 | 只改这一项 |
|------|---------|-----------|
| 画面几乎不动 | 只写外观，没写随时间发生的变化 | 增加一个有起点和终点的可见动作 |
| 主体身份变化 | 新增外貌细节与图片/参考素材冲突 | 删除新增外貌，只写必须保持的部分 |
| 运镜显得随机 | 一个短镜头里塞了多种移动 | 保留一种与画面揭示相关的运镜 |
| 结尾突然中断 | 有动作，但没有结束状态 | 增加一个明确姿态/位置/构图 |
| 首尾帧之间跳变 | 只重复描述两张静态图，没有中间路径 | 写清两帧之间逐步发生的变化 |
| 参考素材互相混合 | 每份文件没有明确职责 | 点名每个编号素材及其用途 |
| 对白被改写 | 对白混在很长的场景描述里 | 把原句单独放入简短说话指令 |
| 否定要求没有效果 | 自然语言否定不一定是硬控制 | 改写成期望的正向状态，删除一个冲突 |
| 动作仓促不连贯 | 30s 内塞了 4+ 个不相关动作 | 精简为单一连续动作弧 |
| 人物 AI 感重 | 只写"真人、电影感"，缺细节 | 逐项加皮肤毛孔/细纹/发丝凌乱/衣料磨损 |

## A/B 测试框架

当不确定哪种写法更好时，做 A/B 测试：

```
测试目标：[你想验证的变量，如"运镜描述方式"]
A 版本：[写法 A，如"镜头缓慢推向她手中的信"]
B 版本：[写法 B，如"slow push in to the letter in her hand"]
控制变量：主体、动作、环境、灯光、时长完全一致
生成次数：各 3 次
评估维度：
  - 运镜是否按预期执行
  - 主体是否保持一致
  - 画面质量
  - 动作连贯性
结论：[A 更好 / B 更好 / 各有优势]
```

## 提示词日志格式

每次生成后记录，建立个人提示词库：

```
日期：2026-08-23
模型：Seedance 2.5
提示词：[完整提示词]
参考素材：[图片/视频/音频列表及用途]
参数：[时长/分辨率/画幅]
结果评分：1-5
成功点：[哪些描述生效了]
问题点：[哪些没生效或产生负面效果]
下次修改：[只改一个变量]
备注：[有效短语存档]
```

## 超详细提示词模板（Sora 2 / 电影级）

当需要精确控制时，使用分区块结构：

```
Style: [整体美学风格，如"1970s 浪漫剧情片，35mm 胶片，自然光晕，柔焦"]
Format & Look: [时长/快门/胶片模拟/颗粒/光晕]
Lenses & Filtration: [镜头型号/滤镜]
Grade / Palette: [高光/中间调/暗部色调]
Lighting & Atmosphere: [光源方向/角度/补光/氛围]
Location & Framing: [地点/前景/中景/背景]
Wardrobe / Props / Extras: [主体服装/道具/群演]
Cinematography:
  Camera shot: [景别+角度]
  Lens: [焦段+景深]
  Motion: [运镜方式+速度]
Mood: [整体情绪]
Actions:
  - [动作 1：清晰的节拍或手势]
  - [动作 2：另一个不同节拍]
  - [动作 3：另一个动作或对白]
Dialogue:
  - [角色]: "台词"
Sound:
  Diegetic: [现场同期声]
  Non-diegetic: [配乐，或 N/A]
```

> 注意：不是每个镜头都需要写满所有区块。不需要的元素留空，给模型创意空间。

## 常见迭代误区

1. **一次改太多**：同时改动作+运镜+灯光，不知道哪个变量起了作用
2. **只生成一次就下结论**：AI 视频有随机性，至少生成 2-3 次再判断
3. **盲目加长**：字数多≠质量高，缺维度的 400 字不如维度齐全的 200 字
4. **堆砌技术参数**："4K HDR 60fps"模型不一定响应，写摄影机型号+焦段+光圈更有效
5. **忽略结束状态**：有动作没结束状态 = 结尾突然中断
6. **否定词依赖**："不要抖动"不如"稳定手持"，否定不一定是硬控制
7. **多动作堆砌**：30s 内塞站起+走路+坐下+拿手机，每个动作都仓促
