## Seedance 2.0 社区结构公式

```
[主体/角色设定] + [场景/环境] + [动作/动态描述] +
[运镜] + [时间轴分段] + [转场/特效] + [声音设计] + [风格/情绪]
```

13–15 秒视频推荐用时间戳分段：

```
0–3s：[开场画面、运镜、动作]
3–6s：[中段发展]
6–10s：[高潮/关键动作]
10–15s：[收束、结局、最后文字/品牌]
```

## 社区运镜补充

在官方词表基础上，社区常用：

- `Hitchcock zoom / dolly zoom`：推拉变焦，制造眩晕
- `whip pan`：快速横摇，制造运动模糊
- `bird's eye / overhead`：鸟瞰/正俯拍
- `FPV`：第一视角穿越机镜头
- `one-take / oner`：一镜到底
- `crane shot`：升降臂镜头

## 社区最佳实践

- 描述要具体有画面感：`穿红风衣的女人走过雨后霓虹闪烁的街道` 优于 `一个女人在走路`。
- 台词用引号包裹，并标角色与情绪：`"总裁，卑微慌乱"`。
- 结尾写禁止项：`禁止出现水印、字幕、Logo`。
- 参考图风格与主题一致：古风用水墨图，赛博朋克用科幻 CG 图。
- 超过 15 秒的视频拆成多段，每段末尾写清楚「衔接点」，用视频延长功能串接。

## 可复用时间码示例（电影感）

```
[0-4s]: 低角度广角静态，一名武士剪影立在血红色落日山脊，长草随风弯曲，远处雷声低沉。
[4-8s]: 推拉变焦至武士面部，背景拉伸变形，主体锁定画面中央，鼓点渐强。
[8-12s]: 快速横摇接升降臂，山谷下千支火把推进，号角响起，烟雾横掠。
[12-15s]: 切至极特写，武士手握刀柄，指节发白，一滴汗慢动作落下，拔刀声后戛然而止。
```
