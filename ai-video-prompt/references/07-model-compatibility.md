# 模型兼容性速查

> 交付前附一行目标模型建议。默认即梦/Seedance 优先。

## 即梦 / Seedance 2.5（主用）

- **IP 过滤严**：避免具名 IP，用描述性替代；删掉版权词换近义词
- 中英文均可，优先优化中文/英语/西班牙语/印尼语/马来语
- 标准生成 4-30s；Long Video 模式 30-180s；Extend Video 对 <30s 原片追加 4-30s
- 原生声画同步，支持对话口型（多语言）
- 支持 ≤30 图 + ≤10 视频 + ≤10 音频（视频/音频总时长各 ≤30s）
- 四种模式：Omni Reference / Smart Edit / Long Video / First and Last Frames
- 官方公式：`[素材说明] + [一句话概括] + [具体情节描述] + [全局补充]`
- 八要素顺序：Format → Subject → Action → Environment → Camera → Look → Timing → Audio & Constraints
- 用正式版，别用 Fast 版；字数超限上电脑网页版

## 提示词风格适配

| 模型 | 推荐风格 | 原因 |
|------|---------|------|
| Seedance 2.5 | 官方四部分公式 + 时间戳 + @素材 | 模型对结构化叙事响应最好 |
| Sora 2 | 分区块详细提示词（Style/Cinematography/Actions/Dialogue） | 模型需要明确的镜头框架和动作节拍 |
| MiniMax H3 | 六要素公式 + 结束状态 + 单运镜 | 模型对"一个主体+一个动作+一个运镜"最稳定 |
| Runway Gen-3 | 简单自然语言 | 模型灵活度高，过度约束反而限制 |
| Kling | 中文自然语言 + 清词 | 中文理解好，但 IP/敏感词过滤极严 |

## 通用建议

- **先 5s 短视频测保真度**，满意再生成 15s/30s
- **多镜作品先锁一致性**（角色设定表 + 氛围锁定），再写每个分镜
- **单变量迭代**：看到结果后一次只改一个变量（动作/运镜/灯光/参考素材）
- 抽卡是常态：简单镜头 2-3 次，复杂运动 20+ 次
- 成片与生成量比例约 1:5-1:10，预算按 5-10×N 规划
- **同一提示词多次生成结果不同**——这是特性，第 2、3 次可能更好
- 复杂任务从较少素材开始，逐步增加（数量是上限不是稳定性建议）
