# 创意激发指南（提升想象力）

> 提示词不仅要准确（九维度、铁律），还要有想象力。套路化的提示词 = 千篇一律的 AI 视频。本指南用于在写提示词前做「创意发散」，找到独特记忆点。

## 创意发散流程（写提示词前必做）

```
用户想法
  → ① 联网找思路：搜索「题材 + 视觉概念 / art direction / 创意短片」
  → ② 概念碰撞：把题材和 2-3 个不相关概念嫁接
  → ③ 生成 2-3 个创意方向，每个方向一个核心视觉概念 + 记忆点
  → ④ 用户选方向（人工审核）
  → ⑤ 再进入文生图/图生视频提示词
```

不要拿到想法就直接写提示词，先花一步做创意发散。用户之前明确要求"内容创意可联网找思路"。

## 7 个创意技巧

### 1. 概念嫁接（最强技巧）

把 A（用户题材）和 B（不相关概念）碰撞，产生新意象。不是简单相加，而是让两者产生化学反应：

| 用户题材 A | 嫁接 B | 新意象 |
|-----------|--------|--------|
| 咖啡品牌 | 蒸汽朋克 | 齿轮驱动的蒸汽咖啡机，吧台是黄铜管道 |
| 智能手表 | 深海 | 表盘像深海窗口，健康数据是游动的鱼群 |
| 美妆 | 微观世界 | 粉底液是流动的星云，口红是岩浆 |
| 火锅 | 冰与火 | 沸腾红油与冰晶共存，食材在冰火交界 |

### 2. 视角创新

换一个没人用过的视角：

- **微观视角**：一滴水里的世界、皮肤纹理里的城市、眼珠里的倒影
- **宏观视角**：上帝视角俯瞰、卫星视角、蚁群视角看人类
- **物体视角**：一把伞的视角、一双鞋的视角、一个茶杯的视角
- **反常规机位**：从地板缝、从下水道、从钥匙孔、从镜子里

### 3. 时间变形

- **时间倒流**：破碎的杯子重新拼合、落叶飞回枝头
- **时间暂停**：世界静止，只有主体在动
- **时间加速**：一天四季流转压缩进 15 秒
- **平行时间**：同一个空间里不同时间线同时上演

### 4. 空间变形

- **空间折叠**：房间翻转、城市对折、上下颠倒
- **无限嵌套**：画面里的画面、梦里的梦、镜子套镜子
- **比例错位**：巨大的日常物件、微缩的城市

### 5. 风格碰撞（有逻辑的混搭）

不是乱堆三个工作室，而是两种风格有逻辑地碰撞出张力：

- 水墨 × 赛博霓虹 = 古意与科技的对撞
- 敦煌壁画 × 电子音乐 = 千年飞天在电子脉冲里复活
- 默片黑白 × 高饱和单色 = 时代错位的孤独感

### 6. 象征隐喻

用具体意象表达抽象概念（而非直接说"孤独""希望"）：

| 抽象概念 | 具体意象 |
|---------|---------|
| 希望 | 废墟里长出的嫩芽、黑暗中唯一亮着的窗 |
| 孤独 | 深海里的鲸、沙漠中的信号塔、空房间里的椅子 |
| 时间流逝 | 墙上剥落的墙皮、慢慢生锈的钟、变长的影子 |
| 记忆 | 褪色的照片、反复倒带的胶片、蒙尘的旧物 |

### 7. 反差反转

- 开头以为是 A，结果是 B：温柔的摇篮曲，画面却是机甲废墟
- 强反差并置：白裙少女站在血红色战场、婴儿哭声配上暴雨
- 期待落空：等了一整个视频的拥抱，最后是擦肩而过

## AI 陈词滥调黑名单（避免或做变形）

这些是 AI 视频的"八股文"，直接写 = 没想象力：

| 套路 | 变形思路 |
|------|---------|
| 缓缓推进 | 换成：从下水道格栅里仰拍、从镜子边缘滑入 |
| 温柔微笑 | 换成：笑到一半僵住、低头时嘴角抽动 |
| 夕阳余晖 | 换成：正午惨白的顶光、绿色路灯下的雨 |
| 樱花飘落 | 换成：铁锈粉尘、纸屑、灰烬、代码雨 |
| 霓虹雨夜 | 换成：干燥的霓虹、日光下的霓虹招牌 |
| 孤独背影 | 换成：孤独的正脸、孤独的一双手 |
| 慢动作回眸 | 换成：极快的一瞥后不再回头 |
| 花瓣飞舞 | 换成：塑料碎片、羽毛、火星 |

**原则**：看到自己写下的第一个画面构思，问一句"这是不是 AI 视频最常见的十个画面之一？" 如果是，换掉或变形。

## 独特记忆点（Hook）

每个视频提示词至少要有**一个独特记忆点**——观众看完能记住的、其他视频没有的画面：

- 不是"一个女孩在车站等车"，而是"一个女孩在车站等一列永远不会来的车，她在给自己写信"
- 不是"一瓶水在旋转"，而是"一瓶水在旋转，水珠在失重中变成星座"
- 不是"汽车在追车"，而是"汽车在追一辆没有司机的车，车的倒影里是另一个人"

## 创意方向选择

创意发散后，给用户 2-3 个方向，每个一句话说清核心概念和记忆点：

```
方向 A：微观视角——粉底液是流动星云，记忆点是"化妆品是宇宙"
方向 B：概念嫁接——美妆 × 深海，记忆点是"珊瑚是口红"
方向 C：风格碰撞——水墨 × 电子音乐，记忆点是"飞天在脉冲里复活"
```

让用户选，不要自己替用户定创意方向。
