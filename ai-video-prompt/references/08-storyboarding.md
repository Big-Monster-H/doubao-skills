# 分镜要点与运镜词典

> 多镜作品 / 复杂分镜时必读。

## 分镜字段标准

每个分镜至少包含：**景别 + 角度 + 运镜 + 时长 + 画面内容 + 情绪/声音**。

```
分镜C001 · 中景 · 平视 · 跟随 · 4s
画面：主角穿过走廊，脚步渐缓，停在门前。
情绪：疲惫→放松。声音：脚步回声。
```

## 运镜与景别词典

| 类别 | 术语 |
|------|------|
| 景别 | 极近特写 ECU / 特写 CU / 近景 / 中景 MS / 全景 LS / 大全景 ELS |
| 角度 | 仰拍 / 俯拍 / 平视 / 过肩 / 高空垂直俯拍 / 主观视角 POV |
| 运动 | 极缓前推 / 环绕 / 跟随 / 固定机位 / FPV / 后拉+下降+上摇 / 摇镜 / 急停 |
| 节奏 | 极缓 / 匀速 / 突然 / 应激性 0.1 秒微颤 / 极慢动作 |
| 呼吸感 | 手持镜头，全程保持极其微弱、类似呼吸般的镜头浮动 |

## 30 秒标准分镜数

| 类型 | 镜数 | 平均时长 | 特点 |
|------|------|---------|------|
| 商品宣传 | 8-12镜 | 2.5-3.8s | 快节奏、产品多角度 |
| 品牌故事 | 5-8镜 | 3.8-6s | 慢节奏、情感沉浸 |
| 动漫短片 | 6-10镜 | 3-5s | 含"間"空镜 |
| 创意短片 | 8-15镜 | 2-3s | 快节奏、视觉冲击 |
| 教育视频 | 4-8镜 | 4-8s | 慢、信息密度 |
| 社交短视频 | 10-20镜 | 1.5-3s | 极快、hook 密集 |

## 开镜三秒法则

观众 3 秒内决定划不划走。6 种高留存开场：

| 模板 | 镜1(0-1s) | 镜2(1-2s) | 镜3(2-3s) | 适用 |
|------|----------|----------|----------|------|
| 悬念型 | ECU 神秘物件 | MS 角色表情 | WS 环境揭示 | 悬疑/故事 |
| 视觉冲击 | EWS 震撼场景 | 缓推 | CU 关键细节 | 旅行/风光 |
| 问题型 | CU 痛点场景 | MS 角色困扰 | 文字"你想过吗?" | 教育/广告 |
| 对比型 | WS Before(灰暗) | WS After(明亮) | CU 产品 | 产品/改造 |
| 动作型 | FS 动态动作 | Whip Pan | MS 落地 | 运动/游戏 |
| 温暖型 | ECU 微笑/手 | 缓拉 | WS 温馨场景 | 品牌/情感 |

## 情绪曲线（按类型）

| 类型 | 曲线 | 节奏 |
|------|------|------|
| 商品宣传 | 倒V：平→快速拉升→高能→回落 | Hook 3 秒抓眼球 |
| 品牌故事 | 缓升：低→渐进→温暖收尾 | 情感积累 |
| 动漫短片 | 三幕剧：起→承→转→合 | 日式"間"留白 |
| 社交短视频 | 锯齿：快节奏多次峰值 | 每 3 秒一个 hook |
| 教育视频 | 阶梯：知识点→案例→总结 | 逻辑递进 |
| 创意短片 | 自由：打破一切规则 | 实验性 |

## 日式「間」(Ma)——留白

日本动画核心美学：空白不是空，是情绪的容器。

| 間的类型 | 时长 | 用途 | 提示词 |
|---------|------|------|--------|
| 風景カット | 3-5s | 空镜/环境/过渡 | establishing shot, scenery, no character |
| 静寂 | 2-3s | 对话间沉默 | quiet moment, stillness, breath pause |
| 足元 | 2-3s | 脚下/物品细节 | feet walking, object detail |
| 食事 | 3-4s | 日常舒缓 | eating scene, daily ritual, calm |
| 天気 | 2-4s | 天空/天气 | sky, clouds, rain transition |

动画建议：每 4-5 镜插入 1 个風景カット（空镜）营造"間"。

## 多镜一致性锁定

多镜作品（3+ 镜）开始写分镜前，先锁两件事，否则第 3-4 镜就漂移：

1. **角色设定表**：每个角色独立描述（年龄/体型/面容/发型/服装/配饰），结尾加"在整个视频中保持一致的身份、服装、发型和外貌"
2. **氛围锁定**：全局色调 + 摄影机 + 风格锚点，所有分镜共用，不逐镜变化
