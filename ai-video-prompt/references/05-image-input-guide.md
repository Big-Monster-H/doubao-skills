# 图生视频与参考图使用指南

> 用户给图片素材时必读。核心：参考图不是越多越好，质量比数量重要。

## 核心原则

**图片质量不高就别喂参考图。** AI 会模仿参考图的*画风*（CG 感、二次元感、马赛克感），而不是它的*设计*。

Mx-Shell 原话："我的所有假面骑士战衣造型都是靠描述让 AI 自由发挥的。" 垫图最大副作用是复现画风而非设计。

## 参考图质量判断

| 参考图类型 | 是否锁定 | 原因 |
|-----------|---------|------|
| 照片级 3D 渲染 | ✅ 可以锁 | 画风本身就是目标 |
| 真实高清实拍 | ✅ 可以锁 | 保真度来源 |
| 低清截图 / 马赛克 / 压缩图 | ❌ 不锁 | 会复现模糊/噪点/压缩伪影 |
| 动漫截图（想要真人） | ❌ 不锁 | 会复现二次元感 |
| 真人照片（想要动漫） | ⚠️ 部分锁 | 只锁五官/构图，风格另写 |
| 商品白底图 | ✅ 锁商品 | 商品保真优先 |
| 角色设定图 | ✅ 锁角色 | 但要写"参照形象，画风另按提示词" |

## 两种用法

### 用法 A：锁定设计（推荐，高质量图）

写"参照上传图片，五官、脸型、发型百分百还原，杜绝美化"——强制锁定，防 AI 自由发挥。

适用于：商品图、角色设定图、高画质实拍。

### 用法 B：只参考不锁定（低质量图或风格冲突）

写"仅参考@图片的构图/动作/大致形象，画风完全按提示词描述执行"——切断画风复现。

适用于：低清图、风格冲突、只想借个构图。

## 即梦 Seedance 的 @素材标注

Seedance 支持 ≤9 张图、≤3 视频、≤3 音频，混合 ≤12 文件。每张图必须用 `@图片N` 明确身份：

| 用途 | 写法 |
|------|------|
| 首帧 | `@图片1作为首帧画面` |
| 角色 | `@图片1的男人` / `参考@图片1的女子形象` |
| 场景 | `他在@图2的电梯中` |
| 商品 | `对@图片2的包进行商业化摄像展示` |
| 材质参考 | `表面材质参考@图片3` |
| 风格参考 | `画风参考@图片4` |

## 多图组合示例

```
参考@图1的男人形象，他在@图2的走廊中，完全参考@视频1的运镜效果，
服装参考@图片3的样式，手中提着@图片4的包
```

## 图生视频检查清单

- [ ] 参考图质量达标吗？不达标改用"只参考不锁定"
- [ ] 每张图有明确 @图片N 身份吗？
- [ ] 风格冲突时切断画风复现了吗？
- [ ] 商品图要求"细节均有所展示"了吗？
- [ ] 素材总数 ≤12 吗？
