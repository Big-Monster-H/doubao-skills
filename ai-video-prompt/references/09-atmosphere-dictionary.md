# 氛围词典：抽象情绪 → 具体视觉现象

> 写提示词时禁止直接使用左列的抽象情绪词，必须翻译成右侧的具体视觉、听觉、动作现象。每个氛围至少选 3-5 个现象组合。

## 温暖 / 治愈 / 亲切

- 午后阳光透过树叶在地面投下移动的斑驳光影
- 晾衣绳上的织物在微风中缓慢摇曳
- 陶瓷杯口冒出的细微热气
- 猫或狗慵懒地靠近人
- 人物把头发拨到耳后的小动作
- 不经意的真诚微笑，随即移开视线
- 听觉：晨间鸟鸣、织物摩擦声、勺子碰杯壁

## 怀旧 / 千禧年记忆

- 褪色的色彩与柔和的对比度
- 老式电线杆和架空电线切割天空
- 墙面斑驳的低层住宅、停在巷口的旧自行车
- 画面上的日期戳
- 听觉：远处摩托车驶过、老风扇转动声、模拟信号底噪

## 孤独 / 疏离

- 大面积负空间构图，人物偏居画面一角
- 空旷街道上唯一移动的身影
- 荧光灯的青白色调、便利店深夜灯光
- 人物长时间静止，只有环境在动（车流、雨、霓虹闪烁）
- 玻璃反光中模糊的人影
- 听觉：空调外机嗡鸣、脚步回声、雨点打在遮阳棚上

## 紧张 / 不安

- 画面边缘偶尔闯入不明物体或人影
- 光源不稳定，灯管闪烁
- 门缝、走廊尽头等纵深阴影
- 手持镜头呼吸感加重，微微颤抖
- 人物频繁回头或停顿倾听
- 听觉：突然中断的环境音、远处不明的金属碰撞声、呼吸声被收进麦克风

## 平静 / 冥想

- 极缓慢的光线变化（云影掠过整个画面）
- 水面或窗帘的规律性微动
- 长镜头，机位几乎不动
- 人物做重复性动作（浇水、叠衣、剥豆）
- 听觉：风穿树叶的沙沙声、水滴声、远处若有若无的生活声

## 热闹 / 生活气息

- 前景不断有人或车穿过镜头
- 摊贩动作细节（翻炒、找零、擦桌子）
- 蒸汽、油烟、热浪扭曲空气
- 近景手部动作 + 中景人流 + 远景车流
- 听觉：叫卖声、锅铲碰撞、多人交谈、自行车铃

## 梦境感 / 记忆感

- 过曝的窗户白成一片
- 胶片颗粒与光晕
- 镜头短，硬切，时间线跳跃
- 人物对镜头挥手或大笑但无声
- 逆光轮廓，面部细节丢失
- 听觉：无声，或只有一层模糊的环境底噪

## 田园 / 乡愁

- 大片稻田或麦田在风中如波浪起伏
- 人物赤脚踩在湿润泥土或田埂上
- 阳光透过树叶在人物脸上流动的光斑
- 远处农舍的炊烟和黑瓦白墙
- 蜻蜓点水、蝴蝶停在花上
- 听觉：蛙鸣虫鸣、风吹稻田、溪流声、公鸡打鸣

## 夏日 / 炎热

- 树影剧烈晃动，光斑密集明亮
- 人物额头和鬓角有细微汗珠
- 冰饮或西瓜表面凝结水珠
- 风扇叶片或蒲扇转动
- 强烈阳光造成高光过曝和镜头眩光
- 热浪扭曲远处景物
- 听觉：蝉鸣、空调外机嗡鸣、冰块碰杯、孩童泼水声

## 通勤 / 都市节奏

- 密集人流与单个主体形成对比
- 室内外/地上地下的曝光剧烈变化
- 低头看手机、翻包找卡等碎片化动作
- 车窗玻璃上反射的模糊面容
- 通勤者身体语言（缩脖子、拉围巾、调背包肩带）
- 听觉：广播播报、列车轰鸣、闸机蜂鸣、匆忙脚步

## 青春 / 慵懒

- 漫无目的闲逛或长时间坐着发呆
- 手部小动作（拨弄衣角、卷头发、转笔）
- 靠在墙边/栏杆上，重心随意切换
- 低头笑、抬头看天、把脸埋进手臂
- 地面影子被拉长，时间缓慢推移
- 听觉：远处电视模糊声、风扇转动声、偶尔笑声后继续安静

## 使用方法

1. 确定情绪后，从对应条目选 3-5 个视觉现象，分配到"地点"段和"时间轴"各镜头
2. 听觉现象直接进"音频"段，与画面元素一一对应
3. 同一提示词避免混用冲突氛围（温暖 + 疏离），除非用户明确要情绪转折
4. 表里没有的氛围，按同样逻辑翻译：**"这种感觉在现实中由哪些可拍摄的物理现象构成？"**
