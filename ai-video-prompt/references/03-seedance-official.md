# 即梦 Seedance 2.5 官方提示词公式

> 来源：Dreamina Seedance 2.5 官方用户手册（2026-08）。
> 适用：即梦/Seedance 多模态输入、首尾帧、@素材标注、产品广告、30s 长视频、视频延长、Smart Edit、白模渲染。

## 平台参数速查（2.5）

| 维度 | 限制 | 稳定性建议 |
|------|------|-----------|
| 图片输入 | ≤ 30 张，300-6000px，单张 ≤30MB | 1-8 个主体效果好；9-12 可尝试但稳定性下降 |
| 视频输入 | ≤ 10 段，单段 2-30s，总时长 ≤30s，480p-4K | 参考图 1-5 张更稳；6-8 张依赖多次生成筛选 |
| 音频输入 | ≤ 10 段，单段 2-30s，总时长 ≤30s，WAV/MP3 | 支持纯音频驱动，不必强制搭配图/视频 |
| 生成时长 | 标准 4-30s；Long Video 30-180s | 视频编辑原片控制在 20s 内 |
| 输出分辨率 | 480p / 720p | — |
| 声音输出 | 原生声画同步，支持对话口型（多语言） | — |

> 数量是上限，不是稳定性建议。复杂任务从较少素材开始逐步增加。

## 四种创作模式

| 模式 | 入口 | 适用 |
|------|------|------|
| Omni Reference | 全能参考 | 图片+视频+音频多模态组合 |
| Smart Edit | 文字修改视频 | 上传视频后用文字说清修改 |
| Long Video | 长视频 | 一次生成 30-180 秒 |
| First and Last Frames | 首尾帧 | 首帧+尾帧约束中间路径 |

## 核心公式（官方 2.5）

```
完整提示词 = [素材说明] + [一句话概括] + [具体情节描述] + [全局补充]
```

| 模块 | 写法 | 要点 |
|------|------|------|
| 素材说明 | 按上传顺序写明每份素材用于角色/场景/动作/音色/镜头参考 | 每份素材必须有明确职责 |
| 一句话概括 | 主体 + 地点 + 事件 + 主题/风格 + 特殊运镜 | 给模型一个全局锚点 |
| 具体情节 | 按时间线写画面、运镜、动作、对白、音效和转场 | 用时间戳分段 |
| 全局补充 | 再次锁定机位、环境、灯光、声音、人物一致性与禁止项 | 收尾防跑偏 |

### 八要素可靠顺序（英文官方）

写长提示词时按此顺序组织，模型理解最稳定：

```
Format → Subject → Action → Environment → Camera → Look → Timing → Audio & Constraints
格式   → 主体   → 动作   → 环境       → 镜头   → 视觉风格 → 时间轴 → 声音与约束
```

## 1. 素材说明（@素材标注）

每个素材必须有明确身份和用途：

| 模式 | 写法 |
|------|------|
| 指定为角色 | `@图片1的男人` / `参考@图片1@图片2长枪角色` |
| 指定为首帧 | `@图片1作为首帧画面` |
| 指定为尾帧 | `@图片2作为尾帧` |
| 指定为场景 | `他在@图2的电梯中` |
| 指定为道具/商品 | `对@图片2的包包进行商业化摄像展示` |
| 指定为风格参考 | `包包的表面材质参考@图片3` |
| 指定为动作参考 | `模仿@视频1的动作` / `完全参考@视频1的所有运镜效果` |
| 指定为音频参考 | `旁白的音色参考@视频1` |
| 指定为节奏参考 | `视频节奏参考@视频` |

多素材组合示例：
```
参考@图1的男人形象，他在@图2的走廊中，完全参考@视频1的所有运镜效果
服装参考@图片1@图片2的样式，手中提着@图片3的包，视频节奏参考@视频
```

## 2. 一句话概括

```
[主体] 在 [地点] [事件]，[主题/风格]，[特殊运镜]
```

示例：`一位红衣舞者在废弃剧院中独舞，电影感写实风格，一镜到底环绕跟拍`

## 3. 具体情节（时间戳控制）

Seedance 2.5 支持文本指定精确时间戳，把指令精确到秒数：

```
0-5s: [开场镜头 + 第一个动作]
6-10s: [第二个动作 + 运镜变化]
11-20s: [主体动作 + 镜头拉远]
21-30s: [收束 + 结束状态]
```

官方示例：
```
0-5s: Open with a close-up of the Overlord from @Image 2. The camera slowly circles his upper body and transitions into a medium shot.
6-10s: The camera steadily circles Consort Yu in a medium shot from @Image 1, following her water sleeves through the arc.
11-20s: The male warrior from @Image 3 enters with an aerial flip. The camera slowly pulls back to a medium-close shot to a full stage view.
```

> 长视频先写全局设定，再把时长切成连续不重叠区间。每段分别写镜头、主体动作、对白/声音和转场，最后补全局一致性与禁止项。

### 动作描述原则

- **单一动作弧**：一个连续的、有起点和终点的动作。✅`她站在窗边，缓慢转身面向镜头，双臂交叉` ❌`她站起、走路、坐下、拿手机`（四个不相关动作塞进 30s 会仓促）
- **动作按节拍写**：✅`演员走四步到窗边，停顿，最后一秒拉上窗帘` ❌`演员走过房间`
- **按时间线叙述**：用叙事性语言，不用技术术语。✅`男人下班后疲惫走在走廊，脚步变缓，最后停在家门口` ❌`生成一个行走动画，逐渐减速`
- **动作具体可视化**：✅`快速将手伸出画框拿起可乐喝了一口，然后露出满足表情` ❌`角色拿起饮料`
- **情绪明确写出**：✅`沉思一会突然崩溃大叫` ❌`角色情绪变化`
- **对话直接写**：✅`用普通话说"做完他的做你的，大家文明排队。"`（支持多语言口型同步）

## 4. 全局补充

```
[机位锁定] + [环境锁定] + [灯光锁定] + [声音] + [人物一致性] + [禁止项]
```

示例：
```
低角度，轻微手持感，上下微幅跟随跳跃轨迹。自然环境声：流水、翅膀有力拍动、鹤鸣。整体氛围宁静、空灵、高度美学。
```

## 真人角色公式

```
角色 = 年龄/种族 + 肤色/皮肤质感 + 五官细节 + 眼神/灵魂 + 发型/发色 + 服装/衣着质感 + 体型/情绪/气质 + 其他要求
```

| 项 | 写什么 |
|----|--------|
| 皮肤 | 冷暖调、真实毛孔、细纹、雀斑或自然瑕疵 |
| 五官 | 眼型、眉骨、鼻梁、唇形、颧骨与下颌线，至少 3-4 项 |
| 眼神 | 注视方向、底层情绪与人物关系 |
| 头发 | 具体发色、质感、发型及风吹/运动后状态 |
| 服装 | 剪裁、颜色、面料、新旧状态和穿着细节 |
| 体态 | 骨架、肩线、构图、动作与整体气质 |

官方示例：
```
22-year-old East Asian woman, with a highly classical, gentle cinematic face. Cool-toned fair skin, revealing a delicate and moist texture, retaining realistic fine pores and natural skin texture. Slender and elegant eyes, a delicate and straight nose bridge, full lips with a faint, gentle smile at the corners. Extremely affectionate and expressive gaze. Jet-black hair pinned into a casual yet elegant classical low bun. Wearing a minimalist, pure white traditional cross-collar dress. Slender figure with delicate narrow shoulders.
```

> 减少 AI 感的关键：不要只写"真人、电影感"。逐项描述并保留雀斑、细纹、发丝凌乱和衣料磨损等真实细节。多人场景给每个人独立脸型、发色、服装和站位。

## 镜头语言

### 方式 A：参考视频运镜（最精准）
```
完全参考@视频1的所有运镜效果
参考@视频1的运镜、画面切换节奏
运镜参考@视频1，推近到屏幕特写，镜头旋转后反转展示全貌
```

### 方式 B：文字描述运镜

| 镜头 | 写法 |
|------|------|
| 一镜到底 | `一镜到底的追踪镜头，从街头跟随...上楼梯、穿过走廊、进入屋顶` |
| 推近 | `镜头前推` / `推近到特写` |
| 拉远 | `镜头拉远展示酒馆全景` |
| 跟随 | `镜头跟随黑衣男子快速逃亡` / `正面跟拍` / `侧面跟拍` |
| 环绕 | `几个环绕镜头展示电梯内视角` |
| 摇镜 | `镜头右摇` / `急停后右摇180度` |
| 俯拍 | `转为空中的俯拍视角` |
| 主观视角 | `第一人称视角` / `从第三人称变成主观视角` |
| 固定镜头 | `固定镜头` |
| 希区柯克变焦 | `主角惊恐时希区柯克变焦` |

景别：`脸部特写` / `手部特写` / `中景` / `全景` / `远景`

> **运镜上限**：一个短镜头里只用 1-2 种有效运镜。同时塞推+摇+环绕+升降会产生浑浊不稳定的运动。一个决定性的运镜通常比四种更好。

## Long Video 长视频（30-180s）

1. 填写完整视频脚本或提示词
2. 模式菜单切换到 **Long Video**
3. 点击时钟图标，选择 30-180 秒
4. 确认画幅、分辨率与时长，点击 Generate

写法：先全局设定 → 时间戳分段（00:00-00:06 / 00:07-00:13 ...）→ 每段写镜头+动作+声音+转场 → 末尾全局一致性与禁止项。

## Extend Video 视频延长

- 只对 **30 秒以内的原始视频** 开放
- 每次追加 4-30 秒，提示词只描述新增部分
- 多轮组合最长可到 60 秒

写法：
```
Reference the content of @video1, extend the video by 10s to continue the story. [新增段落的画面、动作与衔接方式]
```

## Smart Edit 文字修改视频

适合不需要画笔标记、可以直接用文字说清楚的修改：

```
[具体修改对象] + [动作与变化描述] + [生效时间段]
```

示例：
```
Modify everything entirely from 0 to 8 seconds of the overall video. Change the whale in the video to a white dragon. Remove the BGM.
```

## Edit with marks 圈选局部修改

上传本地视频后，用框选/画笔/箭头/锚点标记对象，补充文字要求并确认。系统把标记帧和时间戳加入输入，再按要求修改整段或指定时间段。适合"只改画面中这个位置"。

## 去除字幕和背景音乐

```
Remove the background music from @Video 1. Keep the original dialogue, voice, ambient sound, and on-screen subtitles unchanged.
```

## Clay Renderer 白模渲染

Maya/Blender 等 3D 工作流先用无材质白模确定空间结构、人物站位、运动路径和机位，再交给模型补材质、灯光和风格。

公式：
```
[白模参考的内容] + [角色/场景参考] + [材质与灯光] + [风格] + [完整故事顺序]
```

示例：
```
Refer to @Clay Render 1 for camera movement, pacing, shot-size transitions, subject trajectory, and blocking. Refer to @Image 2 for character design, scene, materials, lighting, color, and fairy-tale atmosphere, and render the white model as a dreamy, warm, 3D animated short.
```

## 七大场景模板

### 产品广告
```
对@图片N的[产品]进行商业化的摄像展示，[产品]的[角度A]参考@图片N，
[产品]的[材质/细节]参考@图片N，要求将[产品]的细节均有所展示，
背景音[氛围描述]
```
进阶版（带场景叙事）：
```
0-Ns画面：[场景建立，产品入场]
N-Ns画面：[产品特写/功能展示]
N-Ns画面：[使用场景/情感连接]
最后N秒：[品牌收束，产品全貌+slogan]
```

### 人物叙事短片
```
@图片1的[角色]在[场景]，[一系列连贯动作描述]，
全程自然对话/旁白，[情绪氛围]
```

### 动作参考复刻
```
参考@图1@图2[角色A]，@图3@图4[角色B]，
模仿@视频1的动作，在@图5的[场景]中[行为]
```

### 创意特效复刻
```
将@视频1的[人物/首帧]替换成@图片1，
完全参考@视频1的特效和动作，[特效变化描述]
```

### 一镜到底
```
@图片1@图片2...@图片N，一镜到底的[镜头类型]镜头，
从[起点]...[中间节点]...最终[终点]
```

### 视频延长
```
将@视频1延长Ns。[新增内容的时间戳分段描述]
注意：生成时长选择 = 新增部分时长
```

### 视频编辑/颠覆
```
颠覆@视频1里的剧情，[新剧情描述]
将@视频1中的[角色A]换成[角色B/图片]，[其他保持不变的要素]
```

## 优化 Checklist

- [ ] 每个 @素材 都有明确用途（角色/场景/动作参考/首帧等）
- [ ] 四部分公式齐全：素材说明 + 一句话概括 + 具体情节 + 全局补充
- [ ] 动作是单一连续弧，有起点和终点
- [ ] 动作按节拍/计数描述，可拍摄
- [ ] 时间戳分段清晰（长视频必做）
- [ ] 运镜 1-2 种，不堆砌
- [ ] 有明确结束状态
- [ ] 情绪/表情/语气有明确描述
- [ ] 音效有暗示（环境音/对话/音乐氛围）
- [ ] 真人角色逐项描述（皮肤/五官/眼神/头发/服装/体态）
- [ ] 素材数量在稳定性建议范围内
- [ ] 时长匹配内容密度

## 常见陷阱

- ❌ 纯技术参数堆砌（"4K，HDR，60fps"——模型不一定响应）
- ❌ 多个不相关动作塞进一个提示词（站起+走路+坐下+拿手机）
- ❌ 超过内容密度的时长（30s 塞 10 个场景切换）
- ❌ @素材标注含糊（只写"参考这些图"）
- ❌ 对话过长（每段对话宜简短有力）
- ❌ 一个镜头塞 4 种运镜
- ❌ 没有结束状态（动作做完突然中断）

推荐：
- ✅ 先 5s 短视频测试保真度，满意再 30s
- ✅ 用即梦先生成参考图（角色设定图/场景图），再作为素材输入
- ✅ 有参考视频优先用"参考@视频的运镜"
- ✅ 商品广告加"细节均有所展示"提升保真度
- ✅ 带对话标语言（中文/英文/方言），模型支持多语言口型同步
- ✅ 复杂任务从较少素材开始，逐步增加
