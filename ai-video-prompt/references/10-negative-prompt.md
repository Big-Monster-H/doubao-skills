# 负面提示词规范

> 负面提示词 = 告诉模型"不要什么"。写对能大幅提升准确度，写错反而召唤出你不想要的东西。

## 核心原则

1. **写名词短语，不写否定命令**：`畸形手指` 优于 `no extra fingers`（部分模型对 `no X` 的否定词理解差，反而强化 X）
2. **只列具体伪影，不列抽象愿望**：`画面模糊、水印、文字乱码` 优于 `不清晰`
3. **负面要与正面自洽**：正面写了"手持呼吸感"，负面就别写"没有抖动"（自相矛盾）
4. **长度克制**：5-15 个短语足够，堆 50 个会让模型不知所措

## 各模型负面字段差异

| 模型 | 负面字段 | 写法 |
|------|---------|------|
| 即梦/Seedance 2.0 | 支持 | 中文/英文均可，写具体伪影 |
| Sora 2 | 无独立字段 | 护栏折进正向提示词，不写否定 |
| Kling 2.x/3.0 | 有 | 写滑动脚、多余手指、形变伪影 |
| Runway Gen-4 | 无（no X 会召唤 X） | 只写应该出现的，负面折进正向 |
| Veo 3/3.1 | 有 | 写名词短语，不是 no 命令 |
| Pika 2.5 | 有 | 2.2 需确认 |
| Hailuo/MiniMax | 有 | 少用，针对具体伪影 |
| Wan 2.x | 强 | 中文伪影词效果稳 |

## 通用负面清单（按需取用）

**人体/角色伪影**：
`多余手指、畸形手指、手部粘连、缺指、肢体变形、错位关节、长短腿、头部与身体比例失调、面部畸形、左右眼不对称、斗鸡眼、多余的肢体`

**画面质量伪影**：
`画面模糊、失焦、运动模糊异常、色块噪点、压缩伪影、水印、字幕残留、文字乱码、低分辨率、马赛克`

**风格负面（去 AI 感/去 CG 感）**：
`塑料感皮肤、油腻高光、游戏CG感、二次元感、卡通渲染、过度锐化、过度磨皮、完美无瑕`

**镜头负面（配合"呼吸感"使用）**：
`僵直镜头、机械运镜、突然抖动、过曝、死黑`

## 各类型专属负面

**动漫**：`真人感、写实皮肤、3D渲染感（除非要3D）、线条断裂、崩坏帧、走形`
**产品**：`产品形变、比例失真、材质错误、Logo乱码、手指遮挡产品`
**真实感**：`电影感运镜、稳定器、商业调色、摆拍感、完美构图、现代色彩分级`
**人像**：`多余肢体、手部畸形、五官不对称、面部粘连、塑料皮肤、磨皮过度`

## 写入提示词的位置

- 支持负面字段的模型：单独放负面字段，不与正向混
- 不支持负面字段的模型（Sora/Runway）：把"不要 X"改写成"只有 X 应该出现"，折进正向描述
- Seedance 图生视频：负面写`不要改变参考图主体身份`、`不要改变商品材质`

## 自检

- [ ] 负面用了名词短语（不是 no 命令）？
- [ ] 与正面描述自洽（没打架）？
- [ ] 长度 5-15 个短语？
- [ ] 按目标模型决定放独立字段还是折进正向？
- [ ] 图生视频写了"不改变主体/材质"？
