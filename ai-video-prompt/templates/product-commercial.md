# 商品宣传视频模板

> 适用：电商、3C、美妆、食品、服饰、家居、运动户外、品牌广告。
> 方法论：Seedance 官方公式（@素材标注）+ 5 段式电影感法（质感段）。

## 七大品类速查

| 品类 | 结构 | 时长/镜数 | 对标参考 |
|------|------|----------|---------|
| 3C数码 | Apple极简 | 30s/10镜 | Apple、大疆、Sony |
| 美妆护肤 | AIDA | 30s/10镜 | Dior、雅诗兰黛 |
| 食品餐饮 | 抖音快节奏 | 15s/12镜 | 麦当劳、日食记 |
| 服饰穿搭 | 故事叙事 | 30s/8镜 | 优衣库、ZARA |
| 家居生活 | AIDA | 30s/8镜 | 宜家、MUJI |
| 运动户外 | 抖音快节奏 | 15s/12镜 | Nike、Adidas |
| 通用/混合 | AIDA | 30s/10镜 | 同品类标杆 |

## 核心骨架（产品广告版 5 段式）

```
1. 核心主题    ← 产品 + 品类调性 + 对标
2. 产品设定    ← 材质/CMF(颜色·材质·工艺)/关键卖点/细节
3. 氛围与质感  ← 摄影机 + 灯光 + 色调（材质即内容）
4. 运镜规则    ← 微距滑轨/环绕/缓推/手持
5. 分镜时间轴  ← 开场钩子→细节→功能→场景→CTA
```

## Seedance 官方产品公式（图生视频优先）

```
对@图片N的[产品]进行商业化的摄像展示，
[产品]的[角度A]参考@图片N，[产品]的[材质/细节]参考@图片N，
要求将[产品]的细节均有所展示，背景音[氛围描述]
```

带场景叙事进阶版：
```
0-Ns画面：[场景建立，产品入场]
N-Ns画面：[产品特写/功能展示]
N-Ns画面：[使用场景/情感连接]
最后N秒：[品牌收束，产品全貌+slogan]
```

## 分镜节奏（通用 AIDA）

| 阶段 | 镜次 | 目的 |
|------|------|------|
| Attention 钩子 | C001-002 | 3 秒抓眼球，最惊艳材质/动态 |
| Interest 兴趣 | C003-005 | 核心卖点特写（材质/功能/细节） |
| Desire 欲望 | C006-008 | 使用场景 + 情感连接 |
| Action 行动 | C009-010 | Logo + CTA + 品牌收束 |

## 关键提示词库

**材质与工艺（3C 核心）**：
`阳极氧化铝边缘倒角、钻石切割高光、拉丝金属纹理、玻璃面板折射、CMF(Color/Material/Finish)、精密工程细节`

**灯光**：
`单侧硬光扫过表面、柔光箱无影棚、环形微距灯、暗场边缘光、纯黑无限背景`

**运镜**：
`微距滑轨推进、360°平滑环绕旋转、缓慢推近、手持轻微呼吸感`

**商品保真句**（必须加）：
`要求将产品细节均有所展示` / `材质与工艺精确还原，杜绝变形` / `产品比例真实，符合实际尺寸`

## 各品类差异化要点

- **3C**：材质即内容，金属拉丝/玻璃折射比文案更有说服力
- **美妆**：质地是关键（精华流动性/粉质细腻/膏体光泽），AIDA 情绪曲线
- **食品**：蒸汽/油光/酥脆声/汁水，快节奏 2s/CUT，原生声画同步
- **服饰**：面料垂坠/走线/版型，故事叙事（上身场景→细节→风格）
- **家居**：光线氛围/空间感，AIDA，宜家式留白
- **运动**：慢动作/汗水/爆发力，快节奏，Nike 式力量感
