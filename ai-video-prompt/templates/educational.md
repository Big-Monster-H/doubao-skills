# 教育/科普视频模板

> 适用：知识讲解、科普动画、教程、产品原理演示、学术概念可视化。
> 方法论：5 段式电影感法 + 教育创作流程（知识点→可视化→讲解脚本→标注）。

## 教育创作流程

```
1. 知识点梳理   ← 拆解为可视觉化单元
2. 可视化方案   ← 图表/模型/动画匹配
3. 讲解脚本     ← 知识→画面映射
4. 教育动画提示词 ← 分镜 + 标注
5. 标注系统     ← 文字/箭头/高亮
6. 质量审核     ← 准确性优先于美观
```

## 核心原则

**准确性优先于美观**。教育视频错一个知识点 = 全盘失败。宁可画面朴素，不可概念错误。

## 知识 → 画面映射

| 知识点类型 | 可视化方式 |
|-----------|-----------|
| 过程/流程 | 分步动画、时间轴推进 |
| 结构/组成 | 分解图、分层展示、标注箭头 |
| 对比 | 并置画面、Before/After |
| 数据 | 图表、趋势线、比例可视化 |
| 抽象概念 | 比喻/类比动画 |

## 情绪曲线（阶梯型）

```
知识点 → 案例 → 总结 → 知识点 → 案例 → 总结
（逻辑递进，不是情感起伏）
```

## 讲解脚本要点

- 每镜一个知识点，信息密度别过高
- 用"问题型开场"：先抛痛点/疑问，再解答
- 标注文字直接写进提示词（模型支持画面文字）
- 对话/旁白标语言（中文/英文/方言）

## 交付清单

- [ ] 知识点拆解清晰，一镜一点
- [ ] 可视化方案匹配知识点类型
- [ ] 标注系统明确（文字/箭头/高亮）
- [ ] 准确性优先，概念无误
- [ ] 信息密度适中（4-8 镜，每镜 4-8s）
