# 动漫/动画视频模板

> 适用：日式动画、国风动画、动漫短片、二次元创作、动画制作流程。
> 方法论：5 段式电影感法 + 日式动画制作管线（世界观→角色→美术板→分镜→作画→摄影处理）。
> ⚠️ 铁律：**用对标作品名，不用工作室名**（"京阿尼风"模型不认识，见 `references/06-art-style-library.md`）。

## 日式动画制作管线

```
1. 世界観設定  ← 世界观/时代/情绪/美术基调
2. キャラ設定  ← 角色设计表（表層外观/中層表情/深層动作）
3. 美術ボード  ← 色彩脚本（朝/午/夕/夜 5 时段色调）
4. 絵コンテ     ← 分镜表（CUT表，含"間"空镜）
5. 作画指示     ← 关键帧/特效作画/日常演技
6. 撮影処理     ← 光线/景深/色彩后期
```

## 画风锚定（必须用作品名）

❌ `Kyoto Animation style / 京阿尼风格`
✅ `《紫罗兰永恒花园》动漫风格，柔和暖光包裹人物轮廓，发丝细腻根根分明，背景如水彩渲染`

角色/背景/特效拆开写：
- 人物 = 《紫罗兰永恒花园》角色画风（柔和线条、细腻发丝）
- 背景 = 《你的名字》渲染风格（超写实、逆光、立体云层）
- 特效 = 《鬼灭之刃》粒子（刀光拖尾、体积光）

完整对标表见 `references/06-art-style-library.md`。

## 角色设计三层

**表層 · 外观**：
```
【发型】长发短发/直卷/单马尾双马尾/发色
【瞳色】蓝/绿/红/金/异色瞳
【体型】纤细/健壮/可爱/高挑
【服饰】制服/和服/铠甲/现代装/奇幻装
【装饰】发饰/眼镜/耳环/纹身/武器
【年龄感】幼年/少年/青年/成年
```

**中層 · 表情神态**：
```
【基本表情】喜/怒/哀/乐/惊/羞/困惑
【眼神刻画】坚定/迷茫/温柔/锐利/空洞/期待
【口型】微笑/大笑/咬牙/喊叫/嘟嘴
【眉毛】上扬/下垂/紧锁/舒缓
【泪水】眼眶含泪/泪珠滑落/大哭
```

**深層 · 演技动作**：
```
【站姿】挺拔/慵懒/警戒/放松
【走姿】大步流星/小碎步/猫步/跛行
【手势】握拳/指天/托腮/挥手/祈祷
【战斗pose】拔刀/格挡/蓄力/收招
【日常小动作】撩发/推眼镜/咬笔/踱步
```

## 作画（Sakuga）技法提示词

**关键帧**：`关键帧动画(sakuga)、タメ(蓄力停顿)→ツメ(加速爆发)→止め(定格)三拍子节奏、流畅中间帧`

**特效作画**：`金田系特效、方块碎片爆炸、黑烟+火花+冲击波、速度线+集中线、能量光效+发光粒子、变形残影`

**动作场景**：`动态分镜/大胆构图、鱼眼透视夸张、动态运镜(PAN+FOLLOW+手持震动)、连续长镜头动作、预备动作(Anticipation)、重力感与速度感`

**日常演技**：`细腻微表情、心理描写作画、空気感(氛围感)、松弛自然动作、睫毛/发丝/衣物的细微运动、光影在脸上的情绪变化`

## 撮影（摄影/后期）处理

**光线**：`体积光从窗户射入、边缘光勾勒轮廓、镜头眩光+鬼影、逆光剪影、圆形散景(bokeh)`

**景深**：`浅景深、前景模糊+中景清晰+背景虚化、运动模糊表现速度感、聚焦拉近(Rack focus)`

**色彩**：`色彩偏移(色収差)、胶片颗粒、暗角、橙青调/蓝紫调/暖金调、色彩溢出(blooming)`

## 场景背景分层

**自然**：天空(新海诚青空/黄昏渐变/星空/阴云)、地形、植被、水体、天候(晴/雨/雪/雾)
**人工**：赛博朋克霓虹街/昭和怀旧商店街/校园/室内/车站/幻想城
**时间光线**：朝(蓝微光+橘地平线)、午(顶光强对比)、夕(金色时刻)、夜(月光/霓虹)

## 分镜「間」(Ma) 留白

每 4-5 镜插入 1 个風景カット（空镜）营造"間"：

| 間类型 | 时长 | 用途 |
|--------|------|------|
| 風景カット | 3-5s | 空镜/环境过渡 |
| 静寂 | 2-3s | 对话间沉默 |
| 足元 | 2-3s | 脚下/物品细节 |
| 天気 | 2-4s | 天空/天气变化 |
