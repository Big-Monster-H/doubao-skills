# 社交短视频模板

> 适用：抖音/快手/小红书/Shorts/Reels 竖屏短快视频。
> 方法论：Seedance 官方公式 + 钩子策略 + 快节奏分镜。

## 核心特点

- 竖屏 9:16
- 极快节奏：1.5-3s/CUT，10-20 镜
- 每 3 秒一个 hook
- 前 3 秒决定划不划走

## 钩子策略（5 选 1）

| 策略 | 写法 |
|------|------|
| 悬念 | `画面第一帧就是神秘物件特写，观众不知道是什么` |
| 视觉冲击 | `开场就是震撼场景，慢推近` |
| 问题 | `痛点场景特写 + 文字"你想过吗?"` |
| 对比 | `Before(灰暗) → After(明亮) 强对比` |
| 动作 | `动态动作 + Whip Pan + 落地` |

## 分镜节奏（锯齿型情绪）

```
峰值 ─ 峰值 ─ 峰值 ─ 峰值
（每 3 秒一个 hook，多次峰值）
```

## 快节奏分镜模板

| 镜次 | 时长 | 内容 |
|------|------|------|
| 1 | 0-1s | 钩子（最抓眼球） |
| 2 | 1-2s | 延续钩子 |
| 3 | 2-3s | 揭示/反差 |
| 4-6 | 3-7s | 主体内容快切 |
| 7 | 7-10s | 互动引导/CTA |

## 文字动画与互动引导

- 画面内文字直接写进提示词（模型支持）
- 结尾加互动引导：`引导点赞关注` / `悬念留到评论区`
- 原生声画同步，可写"快节奏 BGM 卡点"
