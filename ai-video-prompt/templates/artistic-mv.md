# 艺术/MV 视频模板

> 适用：创意短片、音乐视频、艺术概念、实验影像、抽象表达。
> 方法论：5 段式电影感法 + 艺术创作流程（概念→情绪板→实验→策展→节奏→音画同步）。

## 艺术创作流程

```
1. 概念探索   ← 抽象想法→视觉映射
2. 情绪板     ← 色彩/纹理/参考
3. 实验生成   ← 4 方向并行探索
4. 策展筛选   ← 挑最有力的方向
5. 节奏编排   ← 镜头节奏 + 音乐卡点
6. 音画同步   ← 画面与音乐/音效对齐
```

## 概念 → 视觉映射

把抽象概念翻译成具体可拍现象（参考 `references/09-atmosphere-dictionary.md`）：

| 抽象概念 | 具体视觉 |
|---------|---------|
| 孤独 | 大面积负空间、人物偏居一角、荧光灯青白、唯一移动的身影 |
| 梦境 | 过曝窗户、胶片颗粒、硬切跳跃、逆光轮廓 |
| 平静 | 云影掠过、水面微动、长镜头机位不动、重复性动作 |
| 紧张 | 光源闪烁、纵深阴影、呼吸感加重、频繁回头 |

## MV 节奏卡点

| 段落 | 镜头节奏 | 运镜 |
|------|---------|------|
| 前奏 | 极缓、铺垫 | 缓推/固定 |
| 主歌 | 中速 | 跟随/环绕 |
| 副歌 | 快切、卡点 | 摇镜/急停/切镜 |
| 间奏 | 空镜、留白 | 风景/细节 |
| 尾声 | 渐缓、收束 | 拉远/淡出 |

## 创意短片要点

- **打破规则**：创意片可实验性打破 5 段式，但 8 条铁律（禁词/声音/留白）仍要守
- **4 方向探索**：同一概念生成 4 种不同视觉方向，策展筛选
- **音画同步**：画面节奏与音乐节拍对齐，写"切镜节奏卡在重拍上"

## 交付清单

- [ ] 概念已翻译成具体视觉现象（不写抽象词）
- [ ] 情绪板明确（色彩/纹理/参考）
- [ ] MV 有节奏卡点设计
- [ ] 声音行写了（或音乐氛围明确）
- [ ] 结尾留白/收束
