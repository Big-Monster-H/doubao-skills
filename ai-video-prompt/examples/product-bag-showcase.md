# 示例 2 · 商品展示（Seedance 官方公式，图生视频）

> 用途：演示图生视频 + @素材标注 + 产品保真。

## 用户输入

"用这张包的图片做商品展示视频，15秒，要有高端质感"（附：商品白底图 @图片1）

## 需求解析确认

类型：产品宣传 | 时长：15s | 素材：图生视频（1 张商品图）| 画风：高端商业摄影（无对标作品，默认商业质感）| 模型：即梦 Seedance 2.0

## 完整提示词

```
对@图片1的包进行商业化的摄像展示，包的材质与细节参考@图片1，
要求将包的细节均有所展示，材质与工艺精确还原，杜绝形变。

0-3秒画面：纯黑无限背景，包悬浮在暗场中，单侧硬光扫过皮革表面，
         高光沿边缘流动，展现皮革纹理与缝线细节。
3-7秒画面：镜头360度平滑环绕，包缓慢旋转，柔光箱无影棚效果，
         金属五金件反射冷光，皮质纹理清晰可见。
7-12秒画面：镜头推进到五金锁扣特写，微距展示金属拉丝的精密细节，
         环形微距灯无影照明，每个细节毫无遮挡。
12-15秒画面：镜头拉远，包回归居中全貌，品牌Logo在柔光下浮现，
         背景保持纯黑，画面在克制中收束。
背景音：低沉的环境氛围音，无配乐。
结尾：无强光爆炸。只有包在纯黑背景中安静定格，Logo淡入。
```

## 写作意图说明

- 用 `@图片1` 锁定商品形象，并加「材质与细节参考@图片1」「杜绝形变」保真
- 按 AIDA 节奏：钩子(0-3s 材质)→兴趣(3-7s 环绕)→欲望(7-12s 细节)→行动(12-15s Logo)
- 摄影机用「纯黑背景+单侧硬光+柔光箱+环形微距灯」给出明确商业摄影锚点

## 模型建议

Seedance 2.0 图生视频，商品图用白底高清图效果最好；5s 先测保真度，满意再 15s。
