# 示例 3 · 真实感生活流（7段式真实感法）

> 用途：演示「去 AI 感、家庭录像、DV 质感」的完整输出。

## 用户输入

"一段2005年前后的家庭录像感视频，外婆在院子里晒被子，夏天午后，15秒，要像真实DV拍的"

## 需求解析确认

类型：叙事情感/生活流 | 时长：15s（7镜）| 素材：纯文字 | 质感：2000年代初消费级DV（真实感）| 模型：即梦 Seedance 2.0

## 完整提示词

```
主要角色：
约70岁的外婆，短发花白，皮肤有自然的皱纹和晒斑，逼真的皮肤纹理，
穿浅灰碎花棉布短袖上衣，深蓝长裤，脚穿老式塑料拖鞋。
动作缓慢而从容，带着常年劳作养成的习惯性节奏。
在整个视频中保持一致的身份、服装、发型和外貌。

地点：
夏季午后，中国南方老式平房小院。
红砖院墙斑驳，水泥地面有裂纹，墙角堆着旧陶罐和搪瓷盆。
竹制晾衣杆横在院中，晾晒的白色被单在风中鼓动。
院角一棵老梧桐投下晃动的树影，墙上贴着褪色的春联。
没有商店、没有广告牌、没有现代商业元素。

视觉风格：
超现实主义纪录片真实感、真实的即兴行为、自然的肢体语言、
无剧本的日常生活片段感、强烈的环境真实性。

摄像风格：
2000年代初消费级DV画质，中等数字压缩伪影，褪色的色彩，柔和的对比度，
轻微传感器噪点，轻微滚动快门，高光容易过曝，暗部发灰。
强烈的手持抖动，不完美的构图，频繁的自动对焦搜索，
变焦生硬速度不均匀，在阳光和阴影间移动时曝光波动。
没有稳定。没有电影化的摄像机移动。没有现代色彩分级。

时间轴：
00:00-00:02 外婆抱着湿被单从堂屋走出，门槛绊了她一下，稳住后继续。
          树影在她身上晃动，对焦在脸和被单之间来回切换。
00:02-00:04 外婆踮脚把被单甩上竹竿，被单落下盖住了半张脸，
          她伸手撩开，被风吹起的被单啪啪作响。
00:04-00:06 外婆用力把被单拉平，动作停了一下，伸手擦了擦额头的汗，
          阳光透过树叶在她脸上明灭闪烁。
00:06-00:08 她转身走到墙边，端起搪瓷盆里的水，手指擦过镜头边缘留下短暂模糊。
00:08-00:10 外婆弯腰把盆里的水泼向地面，水花在水泥地上散开，
          对焦在盆和水花之间切换。
00:10-00:13 她直起身，望着被风吹鼓的被单，眯眼笑了笑，
          一阵风把她的碎发吹到脸上，她别到耳后。
00:13-00:15 外婆慢慢走向堂屋，镜头停留在空荡的院子，
          被单在风中鼓动两秒后，画面突然切黑。

音频：
仅自然环境音——知了声、风吹被单的噗噗声、泼水声、拖鞋踩在水泥地的声音、
远处偶尔的自行车铃、老风扇的嗡嗡声。
没有音乐。没有音效设计。没有旁白。

目标：
捕捉一个普通夏午的晾晒日常，仿佛一段2005年家庭DV偶然拍下的片段，安静、真实、带着旧时光的暖意。
```

## 写作意图说明

- 核心设定「2000年代消费级DV」决定了所有缺陷：压缩伪影、抖动、对焦搜索、曝光波动
- 时间轴每镜都有「主体动作+环境呼应+一个非完美事件」（门槛绊脚/被单盖脸/擦汗/手指擦镜头）
- 结尾「镜头停留空院→突然切黑」模拟摄像机关闭，收束完整
- 音频与画面一一对应（有被单就有噗噗声，有泼水就有水声）

## 模型建议

Seedance 2.0 正式版，中文提示词；负面提示词可加「稳定画面、电影运镜、商业调色」。
