# 示例 0 · 文生图（Stage A · 动漫首帧）

> 用途：演示「用户想法 → 文生图提示词」的 Stage A 输出。九维度齐全，但**无运镜、无时间轴、无声音**。

## 用户输入

"一个少女在雨后的车站等车，温暖治愈，想要《紫罗兰永恒花园》的感觉，先出首帧图"

## 需求解析确认

阶段：Stage A 文生图（首帧）| 类型：动漫 | 画风对标：《紫罗兰永恒花园》（用户提出）| 目标模型：即梦图片生成

## 文生图提示词（首帧）

```
主体：约17岁少女，柔和圆润脸型，低垂眉眼，眼眸清澈带一丝期待，
      深棕色及肩长发，刘海被微风轻轻吹起，发丝根根分明。
      米白色针织开衫，内搭浅蓝色连衣裙，裙摆有细致褶皱，
      棕色圆头小皮鞋，手边放一把收拢的透明长柄伞。
      坐姿放松，双手轻放膝上，目光望向铁轨远方，
      嘴角带着若有似无的笑意。

环境：日式乡间小车站，雨后地面湿润反光，站台木长椅泛水光，
      前景是站台木椅和少女，中景是铁轨和站牌，
      远景是薄雾笼罩的青山和雨后初晴的天空。

光影：云层缝隙洒下淡金色阳光，柔和的丁达尔光穿过水汽，
      暖光从左侧包裹人物轮廓，地面有水光反射，阴影柔和。

构图：少女居中偏右三分线，坐姿，中景平视，
      视线引导从少女面部→望向的铁轨远方→远处天空，
      浅景深，背景轻微虚化。

色彩：低饱和暖色调，淡金+浅蓝+米白，暗部通透不沉重，
      整体对比柔和。

画风：《紫罗兰永恒花园》动漫风格，柔和暖光包裹人物轮廓，
      背景如水彩渲染，发丝根根分明，线条细腻温柔。

材质：针织开衫纹理清晰可见，裙摆柔软垂坠，木质长椅有自然纹理和雨渍。

细节：长椅表面有细小水珠，地面有浅浅的积水倒影，
      少女刘海有被风吹乱的几缕碎发。

情绪：安静、治愈、略带思念的等待感。

负面：多余手指、畸形手指、五官不对称、崩坏、塑料皮肤、
      过度磨皮、低分辨率、水印、文字乱码、3D渲染感
```

## 写作意图说明

- 这张是**首帧图**，用于 Stage B 图生视频的 I2VA 起点，所以构图和主体状态要定死
- 九维度齐全但**刻意没有运镜和时间轴**——那是 Stage B 的事
- 画风用《紫罗兰永恒花园》作品名 + 拆出「柔和暖光/水彩背景/发丝根根分明」三个可执行特征
